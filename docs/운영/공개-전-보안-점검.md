## 의존성 경고

GitHub 저장소에서 **Dependabot alerts만 활성화**했습니다. 자동 버전 변경과 자동 보안 업데이트 PR은 켜지 않았습니다. 활성화 직후 API 조회에서 열린 경고는 **0건**이었으며, 신규 활성화 후 의존성 분석이 반영되는 데 시간이 걸릴 수 있으므로 공개 전과 제품 개발 시작 시 다시 확인합니다. Lockfile은 저장소에 있습니다. [GitHub Dependabot alerts 안내](https://docs.github.com/en/code-security/how-tos/secure-your-supply-chain/secure-your-dependencies/configure-dependabot-alerts)

알려진 취약점 알림이 없다는 결과가 모든 의존성이 안전하다는 뜻은 아닙니다. 새 경고가 생기면 사용 경로와 영향받는 버전을 확인한 뒤 수정합니다.
