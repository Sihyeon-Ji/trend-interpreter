이 영상은 복잡한 단일 프롬프트 대신 **그래프 공학(Graph Engineering)**을 사용하여 신뢰할 수 있고 효율적인 다중 에이전트 AI 시스템을 구축하는 방법을 설명합니다.

주요 개념 및 구조:
그래프 공학이란? (0:18): 시스템을 노드(에이전트나 결정론적 함수)와 에지(연결)로 구성된 그래프 워크플로우로 설계하는 방식입니다. 이를 통해 모델의 환각을 방지하고 테스트 가능한 구조를 만듭니다.

핵심 설계 패턴

1. Fan-out (병렬 처리) (2:46): 독립적인 작업을 동시에 실행하여 효율성을 높입니다.
2. Join Node (데이터 통합) (3:30): 병렬로 처리된 작업 결과를 하나의 데이터 구조로 통합합니다.
3. Router 패턴 (3:45): 상황에 따라 적절한 에이전트를 선택합니다. 명확한 규칙이 있을 때는 '결정론적 라우터'가, 자유 텍스트 요청에는 'LLM 라우터'가 적합합니다.

시스템 설계 원칙

1. 역할 분담 (2:36): 예측 가능한 작업은 Python 함수(비용 0)로, 복잡한 추론 작업은 모델(LLM)에 할당하여 비용과 정확도를 최적화합니다.
2. 그래프 도입 시점 (5:20): 입력 도착 전 워크플로우를 그릴 수 있다면 그래프 방식을 사용하세요. 복잡한 동적 워크플로우는 Google ADK2를 통해 런타임에 결정할 수 있습니다.
