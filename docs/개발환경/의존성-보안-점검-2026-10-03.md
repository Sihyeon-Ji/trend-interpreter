# 의존성 보안 검사 – 2026-10-03

기존 OSV 검사에서 웹/API lockfile의 7개 패키지, 14개 취약점이 보고됐다. Next.js를 16.3.6, `urllib3`를 2.8.0으로 고정했고, `brace-expansion`의 1·5 계열과 `fast-uri`·`ip-address`를 각각 호환되는 수정 버전으로 올렸다. `shadcn` CLI는 개발 의존성으로 옮겼다. 변경 후 `docker compose run --rm security-check`는 통과했다.

[Next.js 권고](https://github.com/advisories/GHSA-vcvr-r3jv-pc5j)의 영향 범위는 16.3.6에서 수정됐다. 저장소에는 사용자 입력을 받는 `next/og` ImageResponse 경로가 없지만 수정 버전을 사용한다.

[braces 권고](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)는 3.0.3에 영향이 있고 10-03 현재 수정 버전이 없다. 이 저장소에서는 repo가 작성한 ESLint glob과 `shadcn` 빌드 CLI를 통해 참조하며 앱 요청의 패턴을 전달하는 경로는 확인되지 않았다. `apps/trend-web/osv-scanner.toml`에는 **이 ID 하나만**, 이유와 2026-11-02 만료일을 적어 임시 예외로 관리한다. OSV의 `No issues found`는 이 예외를 적용한 결과이지 braces가 수정됐다는 뜻이 아니다. 만료 전 upstream 패치·실제 사용 경로를 다시 확인한다.

검증에는 잠금 파일을 그대로 설치하는 앱 검사·웹 빌드와 E2E를 포함한다. 보안 검사 통과는 실제 Cloud Run IAM·GPU 서빙 또는 사람 평가 완료를 뜻하지 않는다.
