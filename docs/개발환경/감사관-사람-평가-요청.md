# 감사관 사람 평가와 학습 출처 확인 요청

받는 사람 **ejchoi** · 요청일 **2026-10-03** · 회신 희망 **2026-10-08(목)**

## 왜 부탁드리는지

Trend Interpreter에는 유행어 뜻풀이를 읽고 "그대로 써도 되는지(`ok`)", "고쳐야 하는지(`fix`)"를 판정하는 감사관 모델이 있습니다. 지금까지의 평가 정답은 사람이 아니라 모델이 만든 것이라, 새로 학습한 모델이 실제로 나아졌는지 판단할 근거가 없습니다.

그래서 **기존 학습·평가 자료와 겹치지 않는 후보 20건**을 새로 뽑았습니다. 사람 판정이 이 평가의 정답이 됩니다. 이 판정이 있어야 GPU 서버에 올릴 모델을 승인할 수 있습니다.

부탁드릴 일은 두 가지입니다.

1. 후보 20건 판정(1시간 안팎 예상)
2. 기존 감사관 학습 자료의 출처 목록 확인

## 함께 받으시는 파일

| 파일 | 내용 |
| --- | --- |

두 파일은 저장소에 올리지 않는 자료라 따로 전달합니다. 다른 곳에 공유하지 말아 주세요.

## 1. 후보 20건 판정

`review.csv`의 각 행에는 표제어(`canonical`), 뜻(`definition`), 유래(`origin`), 뉘앙스(`nuance`), 근거 주소(`reference_urls`)와 근거 발췌(`reference_excerpts`)가 있습니다. **뜻·유래·뉘앙스가 근거와 맞는지**를 보고 마지막 네 열만 채워 주세요.

| 열 | 입력 |
| --- | --- |
| `label` | `ok` 그대로 써도 됨 / `fix` 고쳐야 함 / `unsure` 근거만으로 판단 불가 |
| `reason` | 판정 이유 한두 문장. `fix`라면 무엇이 틀렸는지 |
| `reviewer` | `ejchoi` |
| `reviewed_at` | 판정 시각, 시간대 포함. 예: `2026-10-06T21:30:00+09:00` |

판정 기준은 다음과 같습니다.

- **`ok`**: 뜻·유래·뉘앙스가 근거와 맞고, 사용자에게 그대로 보여 줘도 오해가 없습니다.
- **`fix`**: 사실이 틀렸거나, 근거에 없는 내용을 지어냈거나, 뉘앙스가 크게 다르거나, 위험한 표현을 순화 없이 설명합니다.
- **`unsure`**: 발췌가 너무 짧거나 근거가 부족해 판단할 수 없을 때만 씁니다. `unsure`는 평가에서 빠지므로, 판정이 확정된 건이 20건보다 적으면 후보를 더 뽑아 추가로 부탁드려야 합니다.

근거 주소를 열어 확인해도 됩니다. 다만 판정은 **"이 뜻풀이가 맞는가"** 기준이고, 문장 표현을 다듬을지는 보지 않습니다.

주의할 점도 있습니다.

- **앞의 7개 열은 고치지 마세요.** 한 글자라도 바뀌면 입력이 변조된 것으로 보고 전체를 거부합니다.
- Excel은 줄바꿈이나 인코딩을 바꿀 수 있습니다. **Google 스프레드시트로 가져와 입력한 뒤 CSV로 내려받는 방법**을 권합니다. Excel을 쓰신다면 "CSV UTF-8" 형식으로 저장해 주세요.
- 행을 추가하거나 삭제하지 마세요.

## 2. 학습 자료 출처 확인

기존 감사관 학습 자료(SFT v5, 371행과 holdout 20행)와 평가 후보가 겹치면 평가가 무의미해집니다. 후보를 뽑을 때 `inventory.json`의 표제어·출처와 겹치는 것은 모두 뺐습니다. 하지만 기존 학습 프롬프트 대부분에 출처 주소가 없어서, 이 목록은 현재 DB에서 **추정해 모은 것**입니다. 실제 학습에 쓴 원본 출처가 빠짐없이 들어 있는지는 자료를 만든 사람만 확인할 수 있습니다.

확인해 주실 것은 다음과 같습니다.

1. SFT v5를 만들 때 쓴 원본 자료와 출처(사이트, 문서, 데이터 묶음)
2. 그 출처가 `inventory.json`의 `source_keys`(도메인과 경로 형태)와 `term_keys`에 모두 들어 있는지
3. 빠진 출처나 표제어가 있다면 그 목록

SFT v5를 직접 만들지 않으셨다면, 만든 분이나 원본 위치를 알려 주시는 것만으로도 충분합니다.

## 회신 방법

아래 두 가지를 보내 주세요.

1. 네 열을 채운 `review.csv`
2. 출처 확인 결과. 짧은 메시지로 주셔도 됩니다.
   - 확인 완료 여부: 빠짐없음 / 빠진 것 있음
   - 빠진 출처·표제어 목록(있을 때)
   - 확인한 사람과 시각

빠진 것이 있으면 목록을 반영해 후보를 다시 뽑고 재검토를 부탁드립니다. 확인이 끝나면 받은 내용으로 판정을 봉인해 기본 모델과 새 학습 모델을 같은 조건에서 비교합니다. 봉인과 비교 절차는 [감사관 독립 사람 평가](감사관-독립-평가.md)에 있습니다.

질문은 언제든 편하게 주세요.
