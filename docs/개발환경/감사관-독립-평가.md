# 감사관 독립 사람 평가

## 현재 상태

학습·중단·재개 smoke 다음 단계로 **모델 판정을 보지 않고 사람이 평가할 후보 20건**을 준비했다. 기존 v5 정답은 모델 판정이므로 독립 정답으로 재사용하지 않는다. 원문·평가 입력·사람 판정은 Git 제외 `artifacts/audit-human-review/`에만 보관한다. Git에는 코드·해시·건수·완료 상태만 남긴다.

현재 묶음은 `artifacts/audit-human-review/20261001-e56b90d/`다. 20건·11개 언어·24개 발췌가 있으며, 기존 SFT/test/holdout 전체의 표제어 328개와 별칭·관련 출처 2,792개를 제외했다. 이 결과는 평가 후보 생성 성공이며 **품질 개선을 입증한 결과가 아니다**. 발췌가 짧거나 판단 근거가 부족하면 `unsure`로 판정한다.

## 후보 재생성·검증

검증된 SQLite 인수와 기존 Dataset manifest를 입력한다. 외부 페이지나 모델을 호출하지 않는다. 서비스와 같은 문서 종류·제목 일치 규칙을 재사용하고 모델 생성 발췌는 제외한다. 언어 순환 방식으로 표본을 골라 동일 입력에서 동일 후보·해시를 만든다. 기존 출력 경로를 덮어쓰지 않는다.

```bash
uv run --project apps/trend-api --locked python -m scripts.prepare_audit_review \
  --snapshot artifacts/snapshots/20261001T224511-e56b90d \
  --dataset artifacts/kaggle/audit-inputs \
  --output artifacts/audit-human-review/new-pack --count 20

uv run --directory models/kaggle/audit --locked python quality.py inspect \
  --pack ../../../artifacts/audit-human-review/20261001-e56b90d
```

출력 `cases.jsonl`에는 고정 프롬프트·근거가 있고 정답은 없다. `review.csv`에서 입력 열은 그대로 두고 다음 네 열만 채운다.

| 열 | 입력 |
| --- | --- |
| `label` | `ok` 그대로 사용 가능, `fix` 수정 필요, `unsure` 근거 부족 |
| `reason` | 근거를 토대로 한 판정 이유 |
| `reviewer` | 실제 검토자 식별자 |
| `reviewed_at` | 시간대가 있는 ISO 8601 시각 |

기존 학습 프롬프트 대부분에는 출처 URL이 없어 SQLite의 모든 근거·뜻 버전 인용과 프롬프트의 URL을 합친 **보수적인 출처 목록**을 사용했다. 목록과 현재 DB가 실제 과거 학습 출처 전체를 포함하는지는 자동으로 증명할 수 없다. 학습 데이터 담당자는 `inventory.json`을 검토하고 누락이 있으면 원본 자료를 보완해 다시 후보를 생성해야 한다. 확인이 끝난 경우에만 별도 비공개 JSON에 `inventory_sha256`(manifest의 실제 값), `training_source_inventory_complete=true`, `confirmed_by`, `confirmed_at`을 기록한다. 코드가 담당자 대신 확인하거나 값을 자동 생성하지 않는다.

## 사람 정답 봉인

```bash
uv run --directory models/kaggle/audit --locked python quality.py seal \
  --pack ../../../artifacts/audit-human-review/20261001-e56b90d \
  --annotations ../../../artifacts/audit-human-review/20261001-e56b90d/review.csv \
  --attestation ../../../artifacts/audit-human-review/20261001-e56b90d/source-attestation.json \
  --output ../../../artifacts/audit-human-review/20261001-e56b90d/gold.json
```

변조·용어/출처 중복·미확인 출처·누락 판정·입력 열 수정은 거부한다. `unsure`는 평가에서 제외하며, 최종 `ok/fix` 두 클래스가 모두 있는 확정 판정 20건 이상이 필요하다. 확정 건수가 부족하면 후보 수를 늘려 새 묶음을 검토한다. 봉인 파일에 출처 확인·검토자·시각·입력 해시를 보존한다.

## GPU 평가·비교

봉인 후 동일 CUDA 환경과 lockfile에서 기본 모델과 체크섬이 고정된 어댑터를 각각 실행한다. 아래 명령은 `models/kaggle/audit/`에서 실행하며 입력과 어댑터는 해당 GPU 환경의 실제 경로에 둔다.

```bash
uv run --locked --extra gpu python quality.py predict --gold /work/gold.json --output /work/baseline.json
uv run --locked --extra gpu python quality.py predict --gold /work/gold.json --output /work/candidate.json \
  --adapter /work/checkpoint-4 \
  --adapter-sha256 825a3aebed1531d0a1355c69e7aaa492967b395a32bf66bf4528df451c5ff676
uv run --locked python quality.py compare --gold /work/gold.json \
  --baseline /work/baseline.json --candidate /work/candidate.json --output /work/comparison.json
```

`checkpoint-4`는 8행 학습 smoke 후보다. 전체 학습 완료 모델이라는 의미가 아니다. 실제 학습 후보가 달라지면 그 파일의 SHA-256을 명시한다. 모델 revision·어댑터 해시·평가셋 해시·학습/평가 코드·lockfile·chat template·추론 옵션을 기록한다. 비교하는 두 실행의 모델과 추론 계약이 같아야 한다.

정확도·수정 탐지 precision/recall·오탐·미탐·JSON 형식 실패·중앙/최대 지연을 계산한다. 형식 실패도 전체 건수에 포함하고 정답이 `fix`이면 미탐으로 센다. 중복·누락 결과나 비정상 지연은 거부한다. 정확도가 엄격히 개선되고 recall·오탐·형식 실패가 악화되지 않을 때만 사람 승인 후보로 추천한다. 지연은 별도로 보고하며 현재 서빙 SLO 충족을 보증하지 않는다. 추천 결과와 관계없이 `promotion_eligible=false`이며 최종 사람 승인·전체 학습·서빙 검증이 남는다.
