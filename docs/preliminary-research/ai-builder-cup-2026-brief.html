02 · 심사 배점

기술 40점이 절반 가까이. "Gen AI를 의미 있게 썼는가"가 핵심

배점 구조상 아이디어가 아무리 좋아도 챗봇 껍데기면 40점 축에서 무너집니다. 반대로 UX는 10점뿐이라 화면 다듬기에 시간을 과투자하면 손해입니다.

Technical Merit & Gen AI Implementation40
Gen AI의 의미 있는 활용, 기술적 건전성, 확장성·지속가능성. 멀티에이전트 오케스트레이션, 도구 호출, 실데이터 연동, 평가 파이프라인이 있으면 이 축에서 차별화됩니다.
Problem Alignment & Impact25
선택한 테마와의 정합성, 명확한 대상 사용자와 가치. "누가, 얼마나 자주, 얼마를 아끼는가"를 숫자로 말할 수 있어야 합니다.
Innovation & Creativity25
기존 솔루션과의 차별성, Gen AI 활용의 창의성. 아래 "레드오션" 리스트에 있는 아이디어는 이 축에서 감점 위험이 큽니다.
User Experience & Solution Design10
직관성, 컴포넌트 간 응집성. 3분 영상에서 흐름이 끊기지 않으면 충분합니다.

1. 챗봇이 아니라 "일을 끝내는" 에이전트

심사 총평이 명시적으로 "프로토타입 데모에서 벗어나 에이전트 시스템으로"였습니다. 조회·요약에서 끝나면 안 되고, 발주·티켓 생성·지급 같은 실행까지 가야 합니다.

SalesShortcut, Cement Ops, Meta Automation QA

2. 사람이 승인하는 지점이 설계에 들어 있음

자율성과 통제를 동시에 보여준 팀이 엔터프라이즈 심사위원에게 강했습니다. 승인 큐, 감사 로그, 근거 인용이 있으면 "프로덕션 준비도"로 읽힙니다.

Cement Ops, AI Governance(Team Success)

3. 멀티모달 입력이 진입장벽을 없앰

사진 한 장, 음성 메모 하나로 시작하는 UX가 임팩트 축과 UX 축을 동시에 잡았습니다. 2026년엔 Gemini Live로 실시간 음성·영상까지 갔습니다.

ArtisanGully, ORION, drone-copilot

4. 설명가능성이 혁신 점수를 만든다

"왜 이렇게 판단했는가"를 보여준 팀이 단순 정확도 경쟁을 이겼습니다. 특히 BFSI·미디어처럼 판단이 민감한 테마에서 결정적입니다.

Parallax, PitchLense

5. 기존 시스템에 꽂힌다

Jira, 결제, MES, 마켓플레이스 API 등 실제 도구 연동이 있으면 "우리 회사에서도 쓸 수 있겠다"는 반응이 나옵니다. 데모용 목업 API라도 연동 구조를 보여주세요.

Meta Automation QA, Ekaette, Call My Parts

6. JAPAC 심사단은 인도 컨텍스트에 과노출됨

운영사 Hack2skill의 수상작 대부분이 인도 문제입니다. 고령화, 재해, 다언어 이커머스, 제조 기술 전승 같은 한·일·동남아 특유 문제는 그 자체로 신선하게 읽힙니다.

04 · 2026 Google 스택

기술 40점을 채우는 재료. 이 중 3~4개를 "이유 있게" 쓰면 됩니다

I/O 2026과 Cloud Next 2026에서 나온 것들입니다. 특별상 "Best Use of Google Cloud AI Tools"는 사실상 이 리스트를 얼마나 유기적으로 엮었느냐로 결정됩니다.

Gemini 3.5 Flash 필수 계열

기본 추론·멀티모달 모델. 코딩·에이전트 벤치마크에서 3.1 Pro를 상회. 비용이 낮아 다단계 에이전트 루프에 적합.

Gemini Live API 차별화

실시간 음성·영상 양방향 대화. 2026년 Google 해커톤 대상작이 전부 이걸로 나왔습니다. 현장·통화·방송 시나리오에 강함.

Gemma 3 필수 계열

오픈 모델. 온디바이스·엣지·프라이버시 민감 처리(공장 현장, 개인 금융 데이터 1차 필터링)에 쓰면 "왜 Gemma를 썼는가"가 설득력 있음.

ADK 2.0 + A2A 차별화

Agent Development Kit. chat / task / single-turn 워크플로우, 병렬 실행, 에이전트 간 A2A 프로토콜. 멀티에이전트 아키텍처 다이어그램의 뼈대.

Agent Platform 명시 요구

Gemini Enterprise Agent Platform. Agent Gateway, Agent Identity, Agent Registry, Skill Registry, Session Memory, 중앙 거버넌스. 엔터프라이즈 통제를 보여줄 때 핵심.

Managed Agents API 신규

Interactions API로 호출하는 Agent-as-a-Service. Google 호스팅 샌드박스에서 실행, MCP 서버 연결 가능. 배포 부담을 줄이면서 "최신 스택" 어필.

Antigravity 2.0 명시 요구

에이전트 기반 개발 플랫폼(IDE + CLI + SDK). 개발 과정에 썼다는 것을 덱과 리포에 기록해 두면 요건 충족과 스토리 둘 다 잡힘.

AI Studio 명시 요구

프롬프트·모델 실험, Android 네이티브 빌드, Antigravity로 내보내기. 초기 프로토타이핑 기록으로 활용.

Cloud Run / Firebase 배포 필수

배포 URL은 반드시 이 둘 중 하나. Firebase는 Auth·Firestore·Hosting까지 한 번에, Cloud Run은 컨테이너 자유도.

BigQuery · Vertex AI Search · Document AI 가산

실데이터를 다루는 티를 내는 재료. BigQuery에 공개 데이터셋(기상, 위성, 거래 로그)을 올려 에이전트가 SQL 도구로 조회하게 하면 기술 축이 두꺼워짐.

Veo 3 · Imagen · Nano Banana · Lyria 미디어 테마

영상·이미지·음악 생성. 미디어/리테일 테마에서 결과물 생성 파이프라인에 넣으면 데모가 화려해짐. 단독으론 혁신 점수 없음.

Evaluation Suite 가산

합성 사용자 시뮬레이션, LLM 평가자, 트레이스 로깅. 리포에 eval 결과 표 하나만 있어도 "기술적 건전성"에서 다른 팀과 갈립니다.

05 · 테마별 아이디어

6개 테마 × 3개. 각각 "왜 이게 뽑히나"와 리스크까지

점수 축은 신선도(레드오션 회피), 기술 40점 적합성(Google 스택 깊이), 데모 임팩트(3분 영상에서 터지는가), 6주 구현 리스크(높을수록 위험)입니다. 앰버 표시가 해당 테마 안에서 추천하는 안입니다.

테마 1

BFSI: Intelligent Risk, Fraud & Financial Experiences

출제 범위는 사기 탐지, 리스크 완화, 프로세스 자동화, 개인화 금융 경험. 거래 이상탐지 분류기는 너무 흔하니 "실시간 개입"이나 "청구·심사 자동화"로 가야 합니다.

ScamShield Live

보이스피싱·로맨스 스캠이 진행되는 통화 도중에 개입하는 실시간 보호 에이전트. 한·일·대만·싱가포르 공통의 고령층 피해 문제.

  • 데모 연출이 관건: 악성 에이전트가 고객 DB를 빼내려다 차단되는 30초 장면을 만들 것
