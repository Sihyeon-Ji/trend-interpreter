## 간략한 설명 (Firebase·Firestore·Cloud Run·Gemini 활용)

양식 칸 'Brief Description of Your Solution (please include how you are leveraging Google services in your submission)'은 **1024자 제한**이다. 아래 문장은 1002자(줄바꿈을 CRLF로 세면 1006자)다(10-17). 숫자는 덱 10쪽(4~9차)과 같다. 덱 15쪽은 상자에 맞춘 다른 판이다.

```text
Trend Interpreter turns one product into local copy for Korea, Japan and English-language markets, with memes in use there now and safe for a brand. Rules pick one meme per market, Gemini writes, rules re-check every line, and a person approves before anything is copied. Every meme links to its risk level and sources.

Google services: Gemini on Vertex AI turns a product photo or line into a brief and writes copy, a video script and a thumbnail plan per market in one structured call, then judges whether copy uses a meme as meant. In the batch, Gemini reads trending Shorts and runs Search-grounded research, Gemma 4 classifies evidence for risk and drafts translations, and ADK runs the agent team. Cloud Run hosts the web app, private API and jobs; Cloud SQL stores the versioned dictionary; Cloud Storage, Secret Manager and Cloud Monitoring support operations. Firebase is not used.

Results: on 12 test cases, picks that fit the product rose from 40% to 91%, with no risky meme shown as safe.
```

Reviewer view (read-only): sign in at /login with user [user] and password [password]. The two Gemma buttons (on a dictionary entry and on the status page) answer that the GPU is off: the L4 VM is defined in Terraform but not deployed, to keep the cost down.
