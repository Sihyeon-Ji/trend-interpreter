| 성승제 | 8 | Future of Work - AI Agent 기반 통합 출입 인프라

개요 : 기관·기업·행사마다 파편화된 출입 신청과 승인 절차를 AI Agent가 연결·자동화하는 통합 출입 플랫폼, 사용자는 신원과 소속을 한 번 인증한 뒤 여러 출입처에 반복적으로 개인정보와 증빙서류를 제출할 필요 없이 출입을 신청할 수 있으며, 출입처는 기존 승인 권한을 유지하면서 신청 검토와 출입증 발급 업무를 효율화

핵심기능

- 통합 디지털 신원·자격 인증 : 신원, 소속, 기자 자격 등의 검증 정보를 한 번 등록하고 여러 출입처에서 재사용

-AI Agent 출입 신청 : 출입처별 신청 조건과 요구 정보를 AI가 파악해 기존 인증정보를 활용하여 신청 절차 자동화
AI 기반 승인 업무 지원 : 신청자의 자격, 제출 정보, 누락 항목 등을 분석해 담당자가 빠르게 승인·보완·거절 판단 지원
-통합 디지털 출입증 : 승인된 기관·행사별 출입 권한을 하나의 서비스에서 관리하고 QR/NFC 등의 디지털 출입증으로 제공

- 출입 시스템 연동 Agent : 소로 다른 기관의 기존 출입·예약·승인 시스템과 연동하여 사용자는 하나의 인터페이스에서 신청부터 승인, 출입증 발급까지 관리 | ❌
