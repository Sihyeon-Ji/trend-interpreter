# Plan 04. 목표 지역 조정과 키워드 대시보드

작성일 **2026-09-28** · 상태 **진행 중 (1~3 구현, 목표 지역 자료 채우는 중)** · 근거 [ADR 0001 §2·§3](../adr/0001-서비스-방향.md) · 목표일 **2026-10-07** · 선행 [Plan 02](02-lifecycle-stages.md), [Plan 03](03-term-risk.md)

## 목표

사용 흐름의 1단계 "살펴보기"를 만듭니다. 사용자가 목표 지역을 고르면 그 지역의 뜨는 밈을 키워드 단위로 보여 줍니다.

## 1. 수집 국가 조정

- `config.py`의 `REGIONS_FOCUS`를 목표 지역 10개국으로 바꿉니다: KR, JP, TW, HK, TH, VN, ID, PH, MY, SG.
- `REGIONS_ALL`은 유지해 미국·브라질·인도·영국 등의 인기 영상·검색어·뉴스는 계속 모읍니다.
- YouTube 검색은 실행당 4개국씩 돌아가므로 하루 약 1,600 unit입니다. 적용 후 하루 사용량을 한 번 확인해 기록합니다.
- 네이버 데이터랩(세대 곡선)은 한국 전용이므로 다른 나라에는 "세대 데이터 없음"으로 표시합니다.

## 2. 지역 필터

- API의 보드·용어 목록·나라 페이지에 `regions` 매개변수를 추가합니다. 없으면 목표 지역 전체입니다.
- 웹은 첫 화면에서 지역을 고르게 하고, 선택은 로그인 사용자의 설정(`reader_prefs`)과 익명 사용자의 쿠키에 저장합니다.
- 중화권은 대만·홍콩으로 표시하고 중국 본토는 선택지에 두지 않습니다.

## 3. 키워드 대시보드

용어 하나를 카드와 상세 화면으로 보여 줍니다.

| 항목 | 데이터 |
| --- | --- |
| 생애주기·확산 단계와 이유 | Plan 02 |
| 리스크 수준과 이유 | Plan 03 |
| 언급 추이(12주) | `mentions_weekly` |
| 검색 관심도 | Google Trends 검색어 순위·대략 검색량(`trend_queries`), 한국은 데이터랩 세대 곡선 |
| 주요 출몰 커뮤니티 | 커뮤니티 근거의 `source_domain` 상위 5개와 건수 |
| 긍정·부정 뉘앙스 | Plan 03의 근거 문장 분류 비율 |
| 근거 | 최근 근거 5건(링크·관측 시각) |

목록은 "지금 뜨는 밈"(확산 단계 `spreading` 우선), "식어 가는 밈", "주의가 필요한 밈"으로 나눕니다.
차트는 기존 `sparkline`, `generation-curves` 컴포넌트를 재사용합니다.

## 4. 화면 문구

- 첫 화면과 메뉴를 마케터·크리에이터 기준으로 다시 씁니다(한국어·영어, `lib/i18n.ts`).
- 기존 지구본 보드는 지역 선택 화면으로, 사전·메시지 해석은 근거 화면으로 둡니다.

## 완료 기준

- 지역을 바꾸면 목록과 수치가 그 지역 데이터로만 바뀝니다.
- 예시 데이터 모드와 API 모드 모두에서 대시보드가 열리고, e2e 테스트에 지역 선택과 카드 열기가 추가됩니다.
- 목표 지역 10개국 모두에 검색어 데이터가 한 번 이상 수집된 것을 확인합니다.

## 결과 (2026-09-28, 원작자 서버 최신 데이터)

### 1. 수집 국가

- `REGIONS_FOCUS` = KR·JP·TW·HK·TH·VN·ID·PH·MY·SG. 검색어는 10개국 모두 최근 14일에 들어와 있다(258~929개).
- 발굴(spot)이 전 세계 조회수 상위 100개만 보던 탓에 인도·영국이 절반, 대만·베트남·필리핀은 0~1개였다 → 목표 지역마다 상위를 고르게 뽑는다.
- 커뮤니티 근거에 홍콩(LIHKG·discuss.com.hk)·필리핀(Reddit·PinoyExchange)·말레이시아(Lowyat 포럼)·싱가포르(HardwareZone 포럼)를 넣었다.
  말레이시아·싱가포르는 본 도메인이 기술 뉴스라 포럼 하위 도메인을 쓴다.
- 위키 밈 분류에 중국어 `网络流行语` 를 넣었다. 간체로 쓴 제목은 본토 말이라 대만·홍콩 표기와 비교해 뺀다(22건 후보). 말레이어·베트남어 분류는
  영어 밈(Anonymous·T-pose 등)을 옮긴 문서뿐이라 넣지 않았고, 태국어·타갈로그어 위키에는 밈 분류가 없다.
- YouTube 하루 사용량 확인은 아직 못 했다(다음 실행 뒤 기록).

**지금 가장 큰 빈칸은 자료다.** 목표 지역별 검증 용어: KR 86 · JP 29 · TW 2 · HK 0 · TH 2 · VN 0 · ID 3 · PH 1 · MY 0 · SG 0 (전 세계 21).
대만은 위키 후보 22건이 조사 대기 중이다. 조사 폭을 실행당 새 표제어 4 → 8개로 늘렸고(Gemini 는 하루 예산이 따로 막는다),
같은 세 용어가 이틀 동안 형식 실패로 칸을 차지하던 문제(모델이 세대 자리에 '90s' 를 넣음)를 고쳤다.

### 2. 지역 필터

- API `GET /dashboard?regions=KR,JP,GLOBAL`. 없거나 모르는 값뿐이면 목표 지역 전체.
- **계획과 다른 점:** 익명 사용자의 선택을 쿠키에 두지 않고 주소(`?regions=`)에만 둔다. `AGENTS.md` 의 "익명은 설정을 갖지 않는다" 규칙과
  계획이 부딪혀서다. 주소를 저장하거나 공유하면 같은 선택이 열린다. 로그인한 사람은 계정의 나라 설정이 기본값이다.
- 용어의 지역은 규칙이다(`pipeline/dashboard.term_regions`): 조사가 정한 쓰는 나라(usage) 가운데 목표 지역 → 없으면 표제어 언어의 나라 →
  목표 지역 밖(미국 등)에서만 쓰이는 영어 표현은 '전 세계' 로 따로 묶는다. 나라 목록에 섞지 않아 "그 지역 데이터로만" 조건을 지킨다.
- 조사 모델이 나라 자리에 빈 문자열을 넣어 36개 용어가 어느 나라에도 속하지 않던 문제를 스키마 검증으로 막았다.

### 3. 키워드 대시보드

- 화면 `/trends`(메뉴 '키워드'), 지구본 나라 패널에서 '이 나라 키워드 보기'. 카드: 퍼진 정도·생애주기·리스크·12주 언급·검색 순위(또는 네이버
  연령대별 검색 추이)·많이 보인 곳·쓰이는 곳. 사전 화면에 '어디서 얼마나 쓰이나'(검색 관심도·주요 출몰 커뮤니티·쓰이는 분위기)를 넣었다.
- 카드는 `dashboard` 단계(board 다음)가 규칙으로 만들어 캐시에 두고, 검수 결정(뜻 승인·제외, 리스크 수준)은 그 카드만 바로 다시 만든다.
- **계획과 다른 점:** 첫 목록 이름을 '지금 뜨는 밈' 대신 **'지금 쓰이는 밈'** 으로 했다. 실제로 오르는 중인 용어가 거의 없고(확산 0, 태동 3)
  대부분 '꾸준히 쓰임' 이라, '뜨는' 이라고 쓰면 거짓말이 된다. 순서는 확산 → 태동 → 주류 → 그 밖, 같은 단계면 최근 4주 언급 순.
- 검색 순위(Google Trends 인기 검색어)에 오른 표제어는 134개 중 3개뿐이었다. 밈 이름은 인기 검색어에 잘 오르지 않는다. 한국어 표제어는 네이버
  데이터랩 연령대별 추이 요약(75개)을 대신 보여 준다. 다른 나라에는 "연령대별 검색 추이는 한국만" 이라고 적는다.
- '주의가 필요한 밈' 은 주의·사용 자제를 모두 모은다. 주의 카드는 쓰이는·식어 가는 목록에도 표시와 함께 남고, 사용 자제는 주의 목록에만 있다.
- 테스트: 지역 규칙·목록 나누기·검색 순위 지역 거르기·카드 즉시 갱신(`test_dashboard_regions_lists_and_search_follow_rules`), e2e 지역 선택과 카드 열기.
