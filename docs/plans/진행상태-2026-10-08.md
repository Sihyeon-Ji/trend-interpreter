## 바로 진행할 순서

1. Plan 02를 보관하고 참조 경로를 갱신한다. 10-06 실측 기록의 702개 분모와 전체 사전의 86.3% `unknown`을 혼동하지 않는다.
2. Compose 전체 검사와 예시 모드 E2E를 실행한다. 데이터가 있는 로컬 DB에서 API 모드 지역 선택과 항목 열기를 확인한다.
3. Plan 15의 최신 지역별 공급과 Plan 03·09의 사람 평가 입력을 확보한다. 모델 출력이나 테스트 통과를 사람 판정으로 대체하지 않는다.
4. Plan 05·06·17·19의 승인 게시 운영 경계를 확인한다. 새 코드 배포와 게시 Job·전용 계정·migration은 실제 적용과 검증 뒤에만 완료 처리한다.

GCP 리소스 생성·배포·결제는 `apps/trend-api/AGENTS.md`에 따라 사용자 확인이 필요하다. 10-10·10-16 운영 갱신, Plan 11 공개 전환, Plan 13의 유료 전환도 이 로컬 점검으로 실행 완료로 바뀌지 않는다.
