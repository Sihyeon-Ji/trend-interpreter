## 1. 지금 상태 (10-10)

추천은 사진·문구 → 제품 이해(Gemini) → 규칙 점수 → 시장마다 상위 몇 개다. 모든 판단은 규칙이고 모델은 제품 이해에만 쓴다. 쓰임 낱말(느낌·쓰임·분야·말투·사용층·종류)은 `term_fit`에 있고, 사람이 고친 값은 `model = human:지시현`으로 고정돼 운영 갱신에서도 이어진다(`refresh_production.carry_fits`).

같은 12사례(3시장 × 4제품) 9차 측정(사람 검토 10-10): 끝까지 된 사례 8/12, 어울리는 추천 10/11(91%), 위험한데 '없음' 0, 카피 즉시 사용성 2.50/3. 상세는 [Plan 09](09-generation-quality-evaluation.md).

## 2. 할 일

### 2.1 빈 시장 – 일본 화장품·러닝화·가계부, 한국 화장품 (추천 0)

원인은 쓰임 낱말이 아니라 **후보 자체가 없다**는 것이다(10-10, 모델 호출 없이 셈).

- 일본 카드 46개 중 27개가 식어 가는 말이라 추천에서 빠진다. 나머지 19개도 대부분 엔터 분야(엔터 13 · 생활 4 · 게임 4 · 음식 1)다.
- 한국 화장품은 드림코어를 뺀 뒤(사람 판정) 남는 말이 없다.

할 일:
1. 일본 수집 보강 – 일본 뉴스·pixiv 백과·위키백과 분류에서 화장품·패션·금융·생활 분야 말을 더 모은다. 수집 서버(PC) 쪽 작업이고, 10-16 마지막 운영 DB 갱신([10-16 운영 DB 갱신](../2026-10-16-final-db-refresh.md))에 들어가야 운영에 반영된다.
2. 새로 들어온 추천 후보는 `fit_backfill.py --gemini`로 쓰임 낱말을 붙이고, 리스크가 비어 있으면 사람이 판정한다(10-10에 36개를 이 방법으로 판정했다 – 표 형식은 `artifacts/risk_review/candidates-20261010.csv`).
3. 식어 가는 말을 일본에서만 허용하는 방법은 쓰지 않는다. 7차 때 철 지난 말(저메추)이 라떼에 추천된 문제가 다시 생긴다.
4. 보강해도 0이면 화면의 '이 시장·분야는 지금 쓸 말이 적다' 안내(이미 있음)로 둔다.

### 2.2 실사진 평가

문구 입력만 측정했다. 사진 경로는 형식·흐름 테스트만 있다.
- 제품 사진 5~10장(직접 찍었거나 CC0)을 준비한다. 사람 얼굴·상표가 드러난 사진은 쓰지 않는다.
- `scripts/eval_recommend.py`에 사진 사례를 더해 같은 네 칸(어울림·위험 누락·뜻대로·즉시 사용성)으로 잰다. Gemini 비용이 든다.

### 2.3 분야 구분 – `fashion_beauty`

분야 낱말에서 패션과 뷰티가 하나(`fashion_beauty`)라, 옷차림 말 OOTD가 수분 쿠션에 두 차례(8·9차) 추천됐다(사람 판정 '어울리지 않음'). `FitCategory`를 `fashion`·`beauty`로 나눌지, OOTD 같은 말만 고정할지 정한다. 나누면 쓰임 낱말을 다시 붙여야 하고(`fit_backfill`) 사람이 고정한 값도 옮겨야 한다.

### 2.4 그 밖

- 추천 개수 완료 기준: 원래 '추천 5개'였지만 규칙 문턱을 넘은 것만 내므로 1~2개인 제품이 많다. 기준을 '최대 5개, 문턱을 넘은 것만'으로 고칠지 팀이 정한다.
- 근거 링크가 홈페이지 주소뿐인 시드 근거(09-29 기준 27개)가 아직 있는지 확인하고, 있으면 실제 문서 주소로 바꾼다.
- 짤 이름 밈(Wojak 등)은 대본·썸네일 그림으로 들어간다. 실제 광고에 쓰려면 그림 권리를 확인해야 한다는 안내를 결과 화면에 둘지 정한다.

## 3. 정할 것 – 10-12 결정(ktwoo)

- **일본 수집 보강:** 한다. 언론·기업 발표·사전류(JC・JK流行語大賞 등, 커뮤니티 글은 쓰지 않음)에서 뷰티·패션·금융·생활 쪽 말을 후보로 넣고, 등재는 기존 조사·게이트가 정한다. 10-15 스냅숏에 넣는다.
- **실사진 평가:** 정식 평가는 하지 않는다(Gemini 비용, 사진 준비). 데모에 쓰는 사진 한 장으로 흐름만 10-16 갱신 뒤 확인한다.
- **`fashion_beauty`:** 제출 전에는 나누지 않는다. 나누면 쓰임 낱말을 다시 붙이고 사람이 고정한 값도 옮겨야 해서 동결 직전에 위험하다. OOTD 가 수분 쿠션에 추천된 사례는 알려진 한계로 둔다.
- **추천 개수:** '최대 5개, 규칙 문턱을 넘은 것만'(지금 동작)을 기준으로 한다.
- **짤 그림 권리 안내:** 넣었다(초안·관리 화면, `feat/approval-records`).

## 5. 완료 기록 (10-16)

- **빈 시장.** 일본 보강(후보 90개, 74개 확정)으로 일본 카드가 46 → 124 가 됐다. 10차에서 추천이 0인 사례는 없다 – 일본 화장품·러닝화·가계부 모두 후보가 나왔다(9차에는 셋과 한국 화장품이 0).
- **10차 재측정(10-15).** 10-14 갱신본에 10-15 정리(비밈 14개 제외, 리스크 사람 판정 2개)를 더한 운영 서비스에서 같은 12사례를 만들기 화면과 같은 웹 API 로 돌렸다. 11/12 완료(한국 가계부 앱은 규칙이 문구를 모두 빼 끝까지 못 감), 어울리는 추천 12/28(43%), 문구에 쓴 밈이 어울린 것 7/11, 위험한데 '없음' 0, 뜻대로 9/11, 즉시 사용성 2.00. 사례마다 후보가 늘었고(11 → 28) 판정은 Claude Sonnet 에이전트가 채점 기준표로 했으며 사람 검토가 없어 9차와 바로 견줄 수 없다([EVALUATION.md](../../../EVALUATION.md), `evals/recommend-rounds.csv` 10행, 원본 `artifacts/eval/recommend-20261015-round10*.json`).
- **실사진.** 정식 평가는 하지 않기로 했다(§3). 운영에서 그린 라떼 그림으로 흐름만 확인했다 – Gemini 가 사진을 읽어 제품 요약·문구에 반영했다([데모 시나리오 v4](../../대회/제출/데모-영상-시나리오.md) 실측은 sng_j).
