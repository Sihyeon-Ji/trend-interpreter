# Plan 08. SNS 카피·숏폼 대본·썸네일 구성안 생성

작성일 **2026-09-28** · 상태 **구현 (모델 품질 평가는 Plan 09)** · 근거 [ADR 0002 §3](../adr/0002-고도화-방안.md) · 목표일 **2026-10-14** · 선행 [Plan 07](07-meme-recommendation.md), [Plan 06](06-gemma-on-cloud-run-gpu.md)의 게시된 사전

## 목표

사용 흐름의 3단계 "만들기"를 만듭니다. 추천에서 고른 밈으로 바로 쓸 수 있는 결과물을 만듭니다.

## 출력

| 결과물 | 내용 |
| --- | --- |
| SNS 카피 | 인스타그램 캡션(해시태그 포함), X 게시글. 각 2안 |
| 숏폼 대본 | 틱톡·릴스용 15~30초. 장면별 화면·자막·대사·길이 |
| 썸네일 구성안 | 주요 문구, 배치, 색, 인물·제품 위치 |

모든 결과물은 입력 언어가 아니라 **목표 지역의 언어**로 만들고, 한국어 설명을 함께 붙입니다.

## 호출 구조

요청 시 모델 호출은 기본적으로 Gemini 생성 한 번입니다([ADR 0002 §3](../adr/0002-고도화-방안.md)).

1. **생성.** Gemini 한 번의 구조화 호출(`pipeline/gemini.py`의 `generate`, JSON schema). 입력은 Plan 07의 제품 설명, 고른 밈의 사전 뜻·뉘앙스·리스크, 톤, 목표 지역.
2. **사전 대조 검사.** 게시된 사전 뜻·리스크와 코드 규칙으로 표현 사용을 대조합니다. 규칙으로 판단할 수 없는 뉘앙스는 Gemini 추가 검사의 필요성과 품질을 Plan 09에서 평가합니다. 어긋나면 한 번 다시 생성하고, 두 번째도 어긋나면 해당 안을 빼고 이유를 표시합니다. 개발자 PC의 Gemma에 실시간으로 연결하지 않습니다.

## 구현

- API: `POST /generate`. 입력은 추천 결과의 용어 ID와 제품 설명이며, 생성 결과는 저장하지 않습니다.
- 웹: 추천 화면에서 밈을 고르면 생성 화면으로 이어지고, 결과마다 복사 버튼을 둡니다.
- 기본 개발 환경에서는 고정된 예시 결과를 돌려줍니다.
- 결과 화면에 "AI가 만든 초안이며 게시 전 확인이 필요합니다"를 표시합니다.

## 완료 기준

- 고른 밈 하나로 세 가지 결과물이 모두 나옵니다.
- 사전 대조 검사에서 걸린 안은 화면에 나오지 않는 테스트가 있습니다.
- 기본 경로의 모델 호출은 1회, 재생성 시 최대 2회인 것을 테스트로 확인합니다. 추가 모델 검사를 도입하면 한도를 다시 정합니다.

## 구현 (2026-09-29)

- `pipeline/generate.py`, API `POST /generate`(JSON: 고른 밈 1~3개·추천이 읽어 낸 제품 설명·목표 지역 하나·톤·화면 언어), 웹은 추천 결과에서 밈을 골라 '카피·대본 만들기'.
- **호출 구조.** 생성은 `gemini.structured(prefer_gemini=True)` — Gemini 가 설정돼 있고 예산이 남았으면 로컬 Gemma 가 켜져 있어도 Gemini 가 만든다(ADR 0002 §3).
  검사는 한 번의 Gemma 호출. 걸린 안이 있으면 문제를 적어 한 번 다시 만들고, 두 번째도 걸린 안은 빼고 이유를 보인다. 호출은 2회, 다시 만들어도 4회
  (`test_failed_items_are_regenerated_once_then_dropped` 가 센다).
- **검사는 규칙이 먼저.** 카피는 고른 밈이 글에 실제로 있어야 하고(`mentions`), 어떤 안도 욕설·선정 표현이 없어야 한다(`unsafe`). 규칙에 걸린 안은 모델에 묻지 않는다.
  모델 검사가 실패하면(형식 오류 등) 규칙 검사만으로 둔다 — 모델 판단 없이 막지는 않는다.
- **말.** 결과물은 목표 지역의 말(한국어·일본어·번체 중국어·태국어·베트남어·인도네시아어·말레이어, 필리핀·싱가포르는 영어). 설명 칸(노트·배치·위치)만 화면 언어.
- 사용 자제 밈은 쓰지 않는다(요청에 넣어도 뺀다). 주의 밈은 '쓸 때 조심' 이유를 프롬프트와 검사에 함께 준다.
- 결과는 저장하지 않는다. 모델이 아예 없는 개발 환경은 고정 예시(화면이 '예시' 라고 알린다). 분당 10회.
- 테스트: 호출 수 2·4, 다시 만든 안 채택, 두 번 걸린 안 제외와 이유, 규칙 검사, 사용 자제 밈 거부, 모델 없는 예시, 목표 지역 밖 거부. e2e 는 추천 → 밈 고르기 → 만들기까지.
