# 결정 기록 (ADR)

제품과 구조에 대한 **확정된 결정**을 한 건씩 남깁니다. 실행 절차와 진행 상태는 [`plans/`](../plans/README.md)에 둡니다.
결정을 바꿀 때는 기존 문서를 고치지 않고 새 번호로 추가한 뒤, 이전 문서의 상태를 `대체됨`으로 바꿉니다.

| 번호 | 제목 | 상태 | 결정일 |
| --- | --- | --- | --- |
| [0001](0001-서비스-방향.md) | 서비스 방향: 마케터·크리에이터용 트렌드 리포트와 숏폼 콘텐츠 생성 | 확정 | 2026-09-28 |
| [0002](0002-고도화-방안.md) | 데이터 파이프라인과 해석 모델 고도화 방안 | 확정 | 2026-09-28 |

## 작성 형식

각 문서는 **배경 → 결정 → 하지 않기로 한 것 → 결과와 후속 작업** 순서로 씁니다. 코드와 데이터로 확인한 현재 상태를 근거로 적고,
확인하지 않은 효과는 기대 효과로 구분합니다.
