# ADR 0001. 서비스 방향: 마케터·크리에이터용 트렌드 리포트와 숏폼 콘텐츠 생성

상태 **확정** · 결정일 **2026-09-28** · 모델 배치 변경 **2026-09-28** · 관련 [ADR 0002 고도화 방안](0002-고도화-방안.md) · [Gemma 로컬 편집 결정](../AI-개발/Gemma-로컬-편집-엔진-결정.md) · [방향 기록](../트렌드/방향.md)

## 배경

Trend 프로토타입은 "세대·문화 간 트렌드 통역"으로 시작했습니다. 유행어의 뜻을 찾아 주는 사전, 나라를 건너는 트렌드를 보여 주는
지구본 보드, 메시지 해석 화면이 이미 동작합니다. 그러나 일반 사용자에게 "뜻을 알려 주는 것"만으로는 돈을 낼 사용자가 분명하지 않았습니다.

대회 주제는 **Media, Content & Digital Experiences**이고, 심사 배점은 기술·AI 구현 40%, 문제 정렬·영향 25%, 혁신 25%, 사용자 경험 10%입니다.
마케터와 숏폼 크리에이터는 유행어의 뜻뿐 아니라 **지금 써도 되는지(수명)**, **써도 안전한지(리스크)**, **어떻게 쓰면 되는지(활용)**를 필요로 합니다.
이 세 가지를 생성형 AI로 채우면 사용자가 분명해지고, 생성 기능이 서비스의 중심이 됩니다.

## 결정

### 1. 대상 사용자

- **브랜드 마케터**: 캠페인 문구에 유행어를 쓰기 전에 수명과 리스크를 확인하려는 사람
- **숏폼 크리에이터와 대행사**: 제품이나 소재에 맞는 밈을 골라 바로 촬영할 대본이 필요한 사람

기존의 세대 통역 기능(사전, 메시지 해석, 세대·나라 맞춤 풀어쓰기)은 없애지 않고, 이 사용자들이 밈을 고를 때 쓰는 근거 화면으로 둡니다.

### 2. 핵심 사용 흐름 (하나의 흐름으로 통합)

"트렌드 리포트"와 "바이럴 콘텐츠 팩토리"를 두 개의 제품으로 만들지 않고, 다음 세 단계의 한 흐름으로 만듭니다.

| 단계 | 사용자가 하는 일 | 서비스가 주는 것 |
| --- | --- | --- |
| 1. 살펴보기 | 목표 지역을 고른다 | 키워드 대시보드: 뜨는 밈, 생애주기 단계, 검색·언급 추이, 주요 출몰 커뮤니티, 긍정·부정 뉘앙스 |
| 2. 추천받기 | 제품 사진이나 홍보 문구를 넣는다 | 사진·문구와 어울리는 밈 추천. 밈마다 생애주기와 리스크 표시("브랜드 공식 계정 사용 주의" 등)와 근거 |
| 3. 만들기 | 추천 중 하나를 고른다 | 인스타그램·X용 SNS 카피, 틱톡·릴스용 숏폼 대본, 썸네일 구성안 |

모든 추천과 생성 결과에는 근거(출처 링크, 관측 시점)를 함께 보여 줍니다. 근거 없는 유행 주장은 내보내지 않습니다.

### 3. 지역 범위

| 구분 | 범위 |
| --- | --- |
| **목표 지역(화면·추천 대상)** | 한국(KR), 일본(JP), **중화권 = 대만(TW)·홍콩(HK)**, 동남아(태국 TH, 베트남 VN, 인도네시아 ID, 필리핀 PH, 말레이시아 MY, 싱가포르 SG) |
| **수집 범위** | 전 세계. 나라를 건너 퍼지는 트렌드를 잡기 위해 기존의 넓은 수집 목록을 유지 |
| **화면 표시** | 사용자가 고른 목표 지역의 데이터만 보여 줌 |
| **중국 본토** | **다루지 않음.** YouTube·Google Trends가 본토 데이터를 주지 않고, 웨이보·더우인·샤오훙수 수집기도 두지 않음 |

집중 수집 국가(`REGIONS_FOCUS`, YouTube 검색 대상)는 목표 지역 10개국으로 바꿉니다. 검색은 한 번에 4개국씩 돌아가며 하므로
하루 약 1,600 unit으로 YouTube 할당량(하루 10,000 unit) 안에 들어갑니다. 현재 집중 국가에 있는 미국·브라질·인도·영국은
넓은 수집 목록(인기 영상, 검색어, 뉴스)에는 남겨 두어, 목표 지역으로 들어오는 해외 트렌드를 계속 감지합니다.

제출 자료에는 "수집은 전 세계, 서비스는 JAPAC 우선, 지역 필터만 바꾸면 다른 권역으로 확장"이라는 확장성을 설명합니다.

### 4. 모델 역할

| 작업 | 모델 |
| --- | --- |
| 카피·대본·썸네일 구성안 생성, 사진 이해, 쇼츠·검색 조사, 필요 시 실시간 자유 서술 | Gemini (Vertex AI) |
| 공개 자료 분류, 검증된 사전 언어판과 국가별 해석 초안 | 개발자 PC의 Gemma 4. [Plan 06](../plans/06-gemma-on-cloud-run-gpu.md)에 따라 검증·검수 후 Cloud SQL 게시 |
| 요청 시 사전 대조·추천 필터 | 게시된 사전·근거 조회와 규칙 코드. 필요한 새 서술은 Gemini로 별도 평가 |
| 생애주기·리스크·검증 상태 판정 | 규칙 코드. LLM은 판정 이유만 서술 |

## 하지 않기로 한 것

- **BGM·춤·파생 드립 연결**: 용어와 노래·춤을 묶는 데이터가 없어 이번 제출에서 제외합니다. 확장 계획으로만 적습니다.
- **중국 본토 데이터**: 위 지역 범위 참고.
- **두 제품 분리**: 리포트와 콘텐츠 생성을 별도 서비스로 나누지 않습니다.
- **"실시간" 표현**: 로컬 편집 파이프라인의 성공 주기가 보장되기 전까지 화면에는 마지막 정상 갱신 시각을 표시합니다. 6시간 갱신을 약속하지 않습니다.

## 결과와 후속 작업

- 기능 구현 순서와 기술 방식은 [ADR 0002](0002-고도화-방안.md)를 따릅니다.
- 집중 수집 국가 조정, 지역 필터, 대시보드는 [Plan 04](../plans/archive/04-target-regions-and-keyword-dashboard.md)에서 진행합니다.
- 화면 문구와 첫 화면은 마케터·크리에이터 기준으로 다시 씁니다. 기존 지구본 보드는 대시보드의 지역 선택 화면으로 활용합니다.
- 웹·API·Cloud SQL 배포([Plan 05](../plans/archive/05-trend-cloud-run-deployment.md))와 로컬 Gemma 편집·게시([Plan 06](../plans/06-gemma-on-cloud-run-gpu.md))는 기능 작업과 병행합니다. 제출 마감은 2026-10-18입니다.
