# 디자인 시안 f-report — 트렌드 리포트형

2026-09-29. `/lab/f-report`(리포트 홈), `/lab/f-report/m/[termId]`(밈 항목). 앱의 현재 화면은 그대로 두고 `/lab` 아래에 더한 검토용 시안이다.
구조는 Pinterest Trends · TikTok Creative Center 의 '지역이 머리, 순위 목록이 몸통, 오른쪽에 고른 것의 미리보기'. 데이터는 실데이터(`DATA_MODE=api`)만 쓰고 숫자를 지어내지 않는다.

## 누구를 위한 무엇인가

- 대상: 브랜드 마케터·대행사·숏폼 제작자. 한국어 먼저, 영어 UI 같이. 분야를 가리지 않는다.
- 첫째 일: "내 시장에서 지금 쓰이는 밈이 무엇이고, 무엇이 늘고 무엇이 식고, 무엇을 피해야 하나". 둘째: "이 밈을 브랜드가 써도 되나(뜻·유래·조심)". 셋째: 만들기(`/recommend`)로 넘어가기.
- 재료의 성격: 밈 대부분은 영상이 없고 이름은 한글·가나·한자·라틴·태국 글자가 섞인다. 그래서 **낱말 자체가 그림**이다 — 이 시안의 힘을 쓰는 한 곳.

- 숫자는 tabular(`.fr-num`). 눈금: 12 · 13 · 15 · 17 · 20 · 24 · 30 · 38 · 48

## 배치

- 1280 컨테이너, 왼쪽 정렬. 숫자는 오른쪽 정렬. 틀은 56px 머리(브랜드 · 리포트/밈 추천 · 찾기 · 언어 · 초안 목록)와 얇은 바닥.
- 리포트 홈: **머리 문장**("지금 한국과 일본에서 쓰이는 밈 24개" — 숫자만 신호색) → 지역 칩(여러 곳 선택, 주소가 상태) → '지난 방문 이후' 띠 → **이번 주 주목** 타일 셋 → 몸통: 탭(지금 쓰이는 / 식어 가는 / 조심할) 위 순위 목록(순위 · 이름+뜻 · 쓰임 추이 · 변화 · 단계, 리스크 표시는 있을 때만) + 오른쪽 고정 미리보기 → 내가 지켜보는 밈 → 밈 추천 단추.
- 휴대폰(390): 타일은 가로 스냅 스크롤, 행을 누르면 항목 화면으로. 넓은 화면(≥1024)에서는 행 클릭이 미리보기를 바꾸고(주소 안 바뀜), 새 탭·Ctrl 클릭은 항목으로 간다.
- 항목: 머리 타일(이름·다른 표기·한 줄 뜻·단계·리스크·이 밈으로 만들기·지켜보기·증감·곡선) → 대표 장면(있을 때) → 유래(위키·기사 출처 붙여) → 이렇게 써요(쉽게 말하면 + 뉘앙스 + 풀어 쓰면) → 쓰임 추이(나이대별 5개, 없으면 정직한 빈 상태) → 나라별 차이 → 출처 → 뜻이 바뀐 기록. 오른쪽 고정 사실표 + 차례.

## 원칙

1. 낱말이 곧 그림. 썸네일이 있으면 같은 타일 안에 앉고, 없으면(대부분) 글자가 그림이다.
2. 지역이 머리. 그 아래 모든 것은 "이 시장에서".
3. 강조색 하나. 늘어남·곡선·선택은 신호색, 식음은 회색, 빨강·호박색은 브랜드 리스크에만.
4. 빈 것은 한 번만 정직하게 — 일본처럼 곡선이 없으면 목록 위에 한 줄, 열은 접는다.
5. 조용한 틀, 뚜렷한 위계 — hairline, 그림자·그러데이션·대문자 eyebrow·화살표 없음.

| 지켜보기 | `localStorage fr:watch` | 미리보기·항목의 ☆. 홈 '내가 지켜보는 밈'에 지금 단계·증감·곡선(고른 지역 목록에 없으면 이름만) |

찾기는 틀에 늘 있다: 실린 목록을 이름·뜻으로 거르고, 없으면 '사전 전체에서 찾기'(`/dictionary?q=`)로 넘긴다.

## 참고에서 가져온 것

- Pinterest Trends: 순위 행 + 고른 것의 오른쪽 미리보기, 행마다 작은 곡선.
- TikTok Creative Center: 지역이 머리 문장의 주어, 순위·추이·단계 열.
- Exploding Topics / Glimpse: 곡선이 곧 카드(타일의 면 곡선), 증감 %를 크게.
- Know Your Meme: 항목의 대표 장면 → 유래 → 퍼짐 순서, 출처 목록.
- Careet: 마케터를 위한 쉬운 한국어 사전 문장 결.
- Google Trends KR: 조건 칩과 왼쪽 정렬 수치.
브랜딩(핑크·검정 히어로·형광)은 가져오지 않았다.

## 일부러 피한 기본값

- 회색 바탕 위 흰 카드와 그림자(SaaS 키트) → 흰 바탕과 hairline, 색이 깔린 면은 주목 타일과 고른 행뿐.
- 초록 오름/빨강 내림 → 오름은 신호색, 내림은 회색, 빨강은 리스크에만.
- KPI 숫자 타일 → 숫자는 머리 문장과 탭 안에.
- 파랑 `#2563EB`·Inter·대문자 eyebrow·가운뎃점 메타·'→' 링크·모노 숫자 → 청록 신호색, Pretendard 하나, 평서문 제목, 동사 링크, tabular 숫자.
- 기간 드롭다운 → 자료가 허락하는 창은 4주 하나라 도장(글)으로만.
- 주목 타일의 1·2·3 번호(마지막에 뺀 장신구) — 목록 순위와 뜻이 달라 헷갈렸다.

## 자료 규칙

- 커뮤니티 근거(kind `community`)는 제목·인용·사이트 이름을 내지 않는다. 보이는 출처는 위키·기사·영상, 그리고 참고 위키 도메인(`wikipedia`, `wiktionary`, `namu.wiki`, `knowyourmeme`, `pixiv`)의 웹 문서뿐(`lib/lab/f-report.ts visibleEvidence`). 미리보기 요약(`app/lab/f-report/api/term/[termId]`)도 서버에서 걸러 브라우저에 커뮤니티 글이 가지 않는다.
- 리스크 사유의 예문(대개 커뮤니티 글)은 떼고 규칙 문장만 남긴다(`cleanRiskReasons`).
- 나라별 차이에서 '근거 부족' 나라는 빼고, 그 나라에서 생긴 말은 24자·3단어 이하 이름꼴만.
- 유튜브 썸네일은 영상 근거 주소에 id 가 있을 때만 `i.ytimg.com` 주소를 그대로 쓴다(저장 안 함). 지금 수집된 영상 근거는 대부분 `https://youtube.com/` 이라 실제로는 거의 안 뜬다.

## 검토 라운드

1. 머리 곡선이 180일 날것이라 지진계처럼 보임 → 7일 이동 평균. 일본처럼 곡선 없는 타일이 비어 보임 → 단계·마지막 확인으로 채우고 높이 줄임. 곡선 없는 목록의 빈 열 → 접음. 나라별 차이의 러시아 행에 커뮤니티 문장·비속어 → '근거 부족' 나라 제외, 짧은 이름꼴만. 항목 첫 줄이 '이렇게 써요'와 겹침 → 첫 줄은 정의, 인용은 '쉽게 말하면'. 바닥글 `p` 안 `div` 로 하이드레이션 오류 → 고침.
2. 1024 에서 이름 열이 160px 로 찌부러짐 → 미리보기 옆에 있을 때 촘촘한 격자. 영어 머리 "…markets 43" → 숫자 먼저. '자료 없음' 회색 2.6:1 → 6.4:1. 항목 절 간격·주제 요약 중복 → 정리.
3. 휴대폰 영어 머리에서 'Find' 단추가 두 줄, 바닥글 '초안 목록' 낱말 중간 줄바꿈 → 찾기 칸 flex, 바닥글 세로 쌓기. 검색 결과에 남던 '1 / 2' 쪽 넘김 → 검색 중엔 숨김. 스핀오프 필터에 영상 제목 통과 → 단어 수 제한. 장신구 하나 제거: 타일 번호.
4. 동작 확인 스크립트(`data/work/lab/f-report/verify.mjs`): 행 클릭 → 미리보기 갱신·주소 불변, ☆ 저장, 칩 → `?regions=KR,JP`, 재방문 띠·지켜보는 밈, Tab 으로 행 이동, 휴대폰 행 → 항목. 콘솔 오류 0.

## 아는 빈틈

- 증감은 한국 검색(네이버 데이터랩)이 있는 표제어에만 있다. 일본·동남아는 단계·마지막 확인·새로 올라옴만으로 움직임을 보인다.
- 검색은 실린 쪽(목록마다 30개)만 거른다. 사전 전체는 링크로 넘긴다.
- '이번 주 주목'은 `rising` 목록 안에서 고른다 — 식어 가는 목록의 급등(예: 팬심 ▲140%)은 타일에 오르지 않는다. 의도한 것이지만 검토 거리.
- 나라별 차이의 '그 나라에서 생긴 말'은 길이·단어 수로만 거른다. 출처가 커뮤니티인지 백엔드가 표시해 주면 규칙을 그것으로 바꿔야 한다.
- 대표 장면은 자료에 거의 없다(영상 근거에 id 없음, `media` 비어 있음). 수집기가 영상 id 를 남기면 타일에 자동으로 앉는다.
- `/lab` 초안 목록 링크는 이 워크트리에 없는 화면을 가리킨다(통합 시 생김).
- 미리보기 요약 라우트(`app/lab/f-report/api/term/[termId]/route.ts`)는 시안 전용이다. 본 앱에 넣는다면 `app/api` 로 옮기는 것이 맞다.

`lib/data.ts` 의 기존 로더만 읽기로 썼다. 스타일은 `app/lab/f-report/f-report.css` 를 이 레이아웃만 불러오고 모든 선택자가 `.lab-f-report` 아래에 있다.
