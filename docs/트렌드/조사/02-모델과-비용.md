# 02 · 모델 선택과 비용 (2026-09-14)

> 이 문서는 `prototype/trend` 시절의 기록이다. 당시 `src/`·`scripts/`·`tests/`는 지금 `apps/trend-api/`, `web/`은 `apps/trend-web/`, `docs/`는 `docs/트렌드/`(조사 자료는 `docs/트렌드/조사/`)에 있다. 명령은 저장소 루트의 `docker compose` 기준으로 바뀌었다(`docs/개발환경/개발-명령어.md`).

## 현재 Gemini 라인업 (공식 문서 기준)

브리프(9/10 작성)는 Gemini 3.5 Flash 를 기본으로 봤지만, 이미 두 세대 뒤다.

| 모델 ID | 상태 | 입력 $/1M | 출력 $/1M | 비고 |
|---|---|---|---|---|
| `gemini-3.8-flash` | GA, 최신 Flash | 0.75 (2026년 내) | 3.75 | agentic video 지원. **기본 선택** |
| `gemini-3.6-flash` | GA | 0.75 | 3.75 | 3.8 과 동일 가격 |
| `gemini-3.5-flash` | GA (구세대) | 1.50 | 9.00 | 더 비싸고 agentic video 미지원 → 쓰지 않음 |
| `gemini-3.5-flash-lite` | GA | 0.30 | 2.50 | 대량 분류·태깅용 후보 |

- Google Search grounding: 월 5,000회 무료(3.x 공유), 이후 $14/1,000.
- 무료 티어는 최신 Flash 기준 **하루 20 요청 수준** 으로 보고됨 → 개발 반복에는 부족. **결제 등록(Tier 1) 필요.**
- YouTube URL 입력: 무료 티어 하루 8시간 분량, 요청당 최대 10개. 프리뷰라 조건 변경 가능.

## 영상 토큰 비용

- 기본 해상도 ≈ 100 tok/초, 고해상도 ≈ 300 tok/초. 60초 쇼츠 ≈ 6k 토큰 (LOW 해상도로 더 줄임).
- 쇼츠 1개 해석 (3.8 Flash, 입력 6k + 출력 0.8k): ≈ $0.0045 + $0.003 = **≈ $0.008**
- 하루 300개 해석: ≈ $2.3/일 → **월 ≈ $70**. Flash-Lite 로 내리면 월 ≈ $25.
- 해커톤 기간(5주) 전체 예상: **$100~150**. 감당 가능.

## 로컬 모델: Gemma 4 (Ollama)

| 태그 | 크기 | 컨텍스트 | 비전 | 용도 |
|---|---|---|---|---|
| `gemma4:12b` (q4_K_M) | 7.6 GB | 256K | O | **개발 기본**. M4 Pro 24GB 에서 여유 |
| `gemma4:e4b` (=latest) | 9.6 GB | 128K | O | 온디바이스 시연용 (모바일급 아키텍처) |
| `gemma4:26b` | 19 GB | 256K | O | 24GB 에서 빡빡함, 비추 |

- 이 맥의 Ollama 0.24.0 은 Gemma 4 미지원 → `brew upgrade ollama` 필요 (수행함).
- 기존 보유: `gemma3n:e4b`, `exaone3.5:2.4b`.

### "왜 Gemma 를 썼나" 에 대한 답 (심사 대비)

1. **쿼터 절약 필터** — 수집된 수백 건을 Gemini 로 다 보내지 않고, Gemma 가 제목·태그로 1차 분류·중복 제거 후 유의미한 것만 넘김.
2. **프라이버시** — 사용자가 붙여넣는 카톡·슬랙 메시지는 개인정보가 섞여 있음. 온디바이스 Gemma 가 이름·번호를 마스킹한 뒤 클라우드로 보냄.
3. **세대 판정의 저지연** — 타이핑 중 실시간 판정은 로컬이 빠르고 무료.
