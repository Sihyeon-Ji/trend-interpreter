# 디자인 시안 F — 에디토리얼 (2026-09-29)

관련 [디자인 개편](디자인-개편.md) · [프론트 방향](프론트엔드.md) · 브랜치 `lab/f-editorial` · 화면 `/lab/f-editorial`, `/lab/f-editorial/m/[termId]`

현재 앱(회색 표 중심의 관리 콘솔 같은 화면)은 그대로 두고, 동료 검토용으로 `/lab` 아래에 더한 시안이다. 방향은 **마케터를 위한 주간 밈
매거진** — 캐릿(Careet)의 정신을 빌리되 브랜딩은 빌리지 않는다. 고른 시장(판)의 '이번 호' 를 읽는 것이 첫 화면이고, 밈 항목은 한 편의 기사다.

## 누구를 위한 무엇인가

- 대상: 브랜드 마케터·에이전시·숏폼 크리에이터. 한국 사용자 우선, 영어 화면 함께. 만드는 콘텐츠의 시장은 한국·일본·대만·홍콩·동남아.
- 첫 번째 일: **매주 한 번**, 내 시장에서 지금 쓰이는 밈·식어 가는 밈·조심할 밈을 한눈에 보고, 하나를 골라 바로 만들러 간다.
- 두 번째 일: **올리기 전**, 밈 하나의 뜻·유래·브랜드가 써도 되는지를 몇 초 안에 확인한다.

## 글꼴과 크기

- **Pretendard Variable 하나.** 이미 전역으로 실려 있고 굵기 45–920 을 쓸 수 있다. 세리프 디스플레이는 검토 뒤 뺐다(아래 '기본값에서 고친 것').
  가나·한자·태국 글자 이름은 시스템 폴백이 맡고 `lang` 을 붙인다(`lib/lang.ts`).
- 역할: 포스터 800 / 자간 −0.045em / 행간 0.95 · 제목 700 / −0.02em · 본문 400 · 라벨 500. 숫자는 `tnum`.
- 크기: 13 · 15 · 16 · 20 · 24 · 32 · 44 · 64 · 96 · 128. 표지 이름 `clamp(52px, 9.5vw, 128px)`, 항목 제목 `clamp(40px, 7vw, 96px)`,
  꼭지 제목 26–32, 카드 이름 24–28, 리드 18–22, 본문 16/1.75, 작은 글 13. 본문 줄 길이 40em 이하.

출처(위키·기사·영상만) → 뜻의 이력. 휴대폰은 한 열이고 사실 칸이 본문 뒤에 온다.

## 원칙

1. **이름이 그림이다.** 밈 대부분에 영상·사진이 없다. 표지도 카드도 이름을 크게 세우고, 유튜브 영상이 실제로 있을 때만 썸네일을 잇는다.
2. **판정은 데이터, 문장은 쉬운 한국어.** 꼭지는 생애주기·목록 규칙으로만 나뉜다. 뜨는 밈이 없으면 "이번 주에는 새로 뜨는 밈이 확인되지 않았습니다" 라고 적는다 — 마케터에게는 '없음' 도 정보다.
3. **구조 장치는 정보다.** 격자선은 칸을 가르고, 바이라인의 세로선은 사실을 가르고, 숫자는 건수다. 번호 매김·눈썹 라벨·장식은 없다.
4. **대담함은 한 곳.** 코발트 표지 하나. 닫는 추천 안내도 조용한 선 하나로 둔다.
5. **커뮤니티 글은 신호로만.** 화면에는 위키·기사·영상만 출처로 나오고, 규칙이 남긴 조심 이유에서도 인용과 사이트 이름을 뗀다(`cleanReason`).
6. 접근성 바닥: 390px 가로 넘침 0, 초점 테두리 3px(표지 위에서는 흰색), `prefers-reduced-motion` 이면 표지 등장 애니메이션 없음, 원문 이름마다 `lang`, 차트는 표로도 본다.

## 참고에서 가져온 것

- 캐릿: 주간 잡지의 리듬, 유행중 스티커, 요즘어 사전의 '이름이 큰' 항목. 노랑·스크립트 로고·사진 콜라주는 가져오지 않았다.
- TikTok Creative Center: 지역이 제목인 구조("한국판 — … 호"), 순위 줄에 추세선.
- Pinterest Trends: 고른 트렌드의 순위 목록 + 성장률(여기서는 검색 관심 %).
- Exploding Topics·Glimpse: 차트가 주인공인 표지, 성장 %.
- Know Your Meme: 항목의 유래·확산 서술, 출처 목록. 광고·다열 배치는 가져오지 않았다.
- Google Trends KR·썸트렌드: 실시간 검색 급증 줄과 그 이유(→ '갑자기 많이 찾은 검색어', 이유를 찾은 것만).

## 기본값에서 일부러 고친 것 (계획 검토)

- 처음 계획의 **세리프 리드**를 뺐다. 크림 바탕+세리프+테라코타는 생성 화면의 흔한 얼굴이고, 가나·태국 이름이 섞이면 세리프가 폴백으로 깨진다. Pretendard 800 대 400 의 굵기 대비로 잡지 느낌을 낸다.
- **테두리·그림자 카드**를 **격자선**으로 바꿨다. 바탕색 틈 방식은 마지막 줄이 덜 차면 회색 덩어리가 남아 칸마다 선을 그리고 줄 끝 칸은 오른쪽 선을 뺀다.
- "COVER STORY" 같은 대문자 눈썹 대신 문장체 라벨 "이번 주 표지". 메타는 가운뎃점 문자열 대신 가는 세로선으로 가른 사실 목록.
- 먹은 `#17191C` 같은 중립 검정 대신 코발트와 한 식구인 남색 `#111A33`.
- 호 번호("제 39호")를 지어내지 않고 보드 시각의 날짜 범위로 쓴다. 표지 밈은 보드의 '지금 쓰이는 밈' 1위(지도의 대표 밈과 같은 규칙).
- 닫는 안내는 처음 계획의 먹색 면을 버리고 선 하나 — 대담함은 표지에만.
- 마지막에 뺀 장식 하나: 호 머리의 소개 문장("고른 시장에서 지금 쓰이는 밈과 …"). 매주 오는 사람에게는 광고 문구다. 갱신 시각만 남겼다.

## 검토 기록

1. 1차: 곡선이 없을 때 표지 오른쪽 열이 비어 별이 화면 가운데 떴다 → 열을 하나로 접고, 곡선 대신 유래·출처를 오른쪽에. 격자 바탕색 방식이 회색 덩어리를 남겼다 → 칸마다 선. 휴대폰 제호 메뉴가 "Englis/h" 로 갈라졌다 → 줄바꿈 금지, 초안 목록은 바닥글로. 갱신 시각을 소개 문장에서 떼어 한 줄로.
2. 2차: 꼭지 건수 22 와 카드 20 이 어긋났다 → 쪽 안의 수만 센다. 일본판에도 네이버(한국) 검색 상승 꼭지가 떴다 → 한국판·전체판만. '새로 실린 밈' 에 시각 대신 이번 호의 단계 붙임표. 휴대폰 칸의 빈 높이 → 내용만큼. 영어 바이라인 첫 글자 대문자. 소개 문장 삭제(장식 하나 빼기).
3. 3차: 조심 이유에 커뮤니티 글 인용과 `(bsky.app)` 이 그대로 나왔다 → `cleanReason` 으로 뗀다(카드·항목·사실 칸 한 곳에서). 나라별 차이의 "근거 부족: 확인되지 않음" 자리 표시를 문장처럼 내지 않는다. 상호작용 실측: 별표 2개 → 새로고침 뒤 유지, 방문 시각을 어제로 돌리면 띠가 "… 방문 이후 32건", 찾기 두 글자에 목록 1건, Tab 으로 표지 버튼까지 가면 흰 초점 테두리, `reducedMotion: reduce` 에서 애니메이션 없음.

## 아직 못 한 것

- 차트에 마우스 십자선·툴팁이 없다(서버 SVG). 표로 보기와 정점 월만 있다.
- 판은 한 지역씩이다(전체판 제외). 여러 시장을 같이 고르는 것은 없다.
- 검색 상승 %는 나이대별 상대값(각 나이대 최대 100)을 평균낸 거친 지수다. 캡션에 계산법을 적었지만 절대 검색량은 아니다.
- 목록의 2쪽 이후는 "다음 쪽" 링크로만 넘긴다(식는 중 69, 조심 34).
- 영상 썸네일 분기는 있으나 지금 데이터에 유튜브 id 가 있는 근거가 없어 화면으로 확인하지 못했다.
- 영어 화면의 조심 이유는 일반 문장이다(규칙이 남긴 이유가 한국어뿐). '새로 실린 밈' 은 지역이 없어 모든 판에 같이 나온다.
- 검색 급증은 이유를 찾은 것만 싣는다(원인 미확인은 뺐다).
- 공용 파일은 건드리지 않았다. 굳이 고친다면: `lib/data.ts` 에 곡선 여러 개를 한 번에 받는 로더가 있으면 한국판에서 항목마다 한 번씩 묻는 것(59회, 300초 캐시)을 줄일 수 있다.
