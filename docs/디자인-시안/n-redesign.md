# 시안 n-redesign – '누가 정했나' 원장(ledger)

주소: `/lab/n-redesign`(만들기), `/lab/n-redesign/drafts`(시장별 초안), `/lab/n-redesign/explore?m=KR`(둘러보기), `/lab/n-redesign/term/[id]`(표제어: `jangwonyoung`, `bamti`, `luckyvicky`, `oshikatsu`, `mugunghwa`).
데이터는 `apps/trend-web/lib/lab/n-redesign/data.ts` 의 손으로 옮긴 예시뿐이다(백엔드 호출 없음).

## 개념

1. 업종을 타지 않는 흰 종이·검정 글자·hairline 위에서, 화면의 모든 판단 옆에 **누가 정했는지**를 붙인다: 규칙(실선 테두리), 모델(점선 테두리), 검수자(서명 잉크로 채움).
2. 표제어는 번역하지 않는 원문 그대로 크게 놓는다. 화면의 '그림'은 낱말 자체다.
3. 왼쪽 이름표, 가운데 내용, 오른쪽 여백 주석으로 이뤄진 '원장' 격자를 모든 화면이 같이 쓴다. 대기업 제품처럼 조용하고, 데모 영상에서는 'AI 가 일했고, 규칙이 정했고, 사람이 승인했다'가 한눈에 읽힌다.

## 토큰

| 이름 | 값 | 쓰임 |
|---|---|---|
| 종이 | `#FFFFFF` | 바탕 전부 |
| 먹 | `#000000` | 글자, primary 버튼, 고른 것(토글 채움), 굵은 구분선 |
| 회색 1 | `#525252` | 보조 글(7.8:1) |
| 회색 2 | `#6B6B6B` | 메타·날짜(5.3:1) |
| 선 | `#E5E5E5` / `#C9C9C9` | hairline / 포스터 테두리 |
| 입력 경계 | `#8A8A8A` | 입력·토글 테두리(3.4:1, 비텍스트 3:1 충족) |
| 우물 | `#F4F4F4` | 포스터 자리에만(중성 회색, 틴트 아님) |
| 서명 잉크 | `#24339B` | **유일한 강조색.** 사람의 결정(승인 표지, 승인 상태)과 키보드 초점에만(약 10:1) |
| 쓰지 않음 | `#B3261E` | 상태 전용, 늘 낱말(또는 취소선)과 함께 |
| 조심해서 | `#8A5300` | 상태 전용, 늘 낱말(또는 점선 밑줄)과 함께 |

강조색 근거: 파란-검정 만년필 잉크. '승인'이라는 사람의 행위에만 색을 주면 데모에서 사람이 개입한 지점이 저절로 눈에 걸린다. 흔한 SaaS 파랑(밝은 코발트)보다 어둡고 채도가 낮아 흰·검 화면에서 튀지 않는다.

모서리: 버튼·입력 6px, 표지 3px, 포스터 2px, 칩 완전 둥근(선택지라는 뜻). 그림자 없음.

## 원칙

- 판정 옆에는 늘 표지. 표지 셋은 선 모양과 낱말이 함께 달라 색을 못 봐도 구분된다.
- 번호는 실제 순서(초안이 만들어진 4단계)에만 단다.
- 빈 데이터는 이유를 말한다: 태국은 '밈 없이 씀'을 표본 자리에 회색으로 그대로 두고 "확인된 말 9개 중 맞는 말이 없어 억지로 넣지 않았다"고 쓴다. 둘러보기의 얇은 시장도 같은 문장.
- 낱말 구름은 흩뿌리지 않고 활자 견본처럼 한 문단으로 흐른다. 크기는 **그 시장 안의** 4주 언급 순위 다섯 단계. 쓰지 않는 말은 빨강 취소선, 조심할 말은 호박 점선 밑줄, 다른 나라에서도 쓰면 `+n`.
- 움직임은 하나: 승인을 누르면 서명 표지가 찍히듯 들어온다(`prefers-reduced-motion` 이면 없음).

## 버린 것과 이유

- 대시보드 카드 격자(숫자 타일 + 차트 카드): 회색 관리자 콘솔이 되고, '누가 정했나'가 안 보인다.
- 시장별 색: 나라마다 색을 주면 강조색이 열 개가 된다. 시장은 이름과 순서로만 구분.
- 신호등 3색 리스크 칩: 칩 덩어리가 화면을 채운다. 리스크는 낱말 하나에 색만.
- 포스터 자리에 가짜 그림(그라디언트·도형): 이미지 만들기가 꺼져 있다는 사실을 가린다. 점선 자리와 문장으로 정직하게.
- 단계(생애주기)를 색 막대로: 여섯 칸 눈금 중 지금 칸만 먹으로 채우고 낱말을 붙였다.
- 두 번째 서체(세리프 표제): 한·태 글리프를 다 가진 짝이 로컬에 없고, 원문 표본이 이미 개성을 낸다.

## 품질 확인
