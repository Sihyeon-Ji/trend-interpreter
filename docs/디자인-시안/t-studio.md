# 디자인 시안 — 마케터 스튜디오형 (`/lab/t-studio`)

2026-10-01 · 팀원의 화면 기획 초안(`trend-tongyeok` v2)을 Opus 5.5가 다듬은 v3 · **예시 데이터로만 도는 화면**

- 화면 `/lab/t-studio` — 한 파일짜리 화면을 창 가득 띄운다(`app/lab/t-studio/proto` 가 HTML 을 내보내고, `page.tsx` 가 iframe 으로 감싼다)
- 화면 안의 이동은 `#해시`: `#radar`(이번 주 트렌드)·`#meme-yar`(밈 자세히)·`#studio`·`#regions`·`#decoder`·`#library`·`#check`·`#plans`·`#report`·`#settings`
- 파일: `app/lab/t-studio/**`, `components/lab/t-studio/**`, `lib/lab/t-studio/**`(원본 `source/`, 생성 파일 `prototype-html.ts`)
- 고치는 법: `lib/lab/t-studio/source/` 의 `src/`·`data/` 를 고치고 `python3 apps/trend-web/lib/lab/t-studio/source/build.py` 로 `prototype-html.ts` 를 다시 만든다
- 다른 초안과 다른 점: 실데이터(`lib/data.ts`)를 쓰지 않고, 브랜드·기획안·주간 리포트처럼 **지금 백엔드에 없는 기능**이 들어 있다. 고르게 되면 실제 화면으로 옮길 때 아래 '실제 프로토타입과 맞춰야 할 것' 표대로 나눠야 한다

## 무엇을 위한 화면인가

| | |
| --- | --- |
| 쓰는 사람 | 브랜드 마케터. 한 브랜드(예: 아이스 흑당 라떼)의 분야·타깃·말투·올리기까지 걸리는 시간을 기준으로 본다 |
| 첫 화면의 일 | "이번 주 쓸 밈·먼저 쓰면 좋은 밈·피할 밈" 세 장, 그리고 카드에서 바로 근거나 기획으로 |
| 다른 초안과 다른 점 | 보는 데서 끝나지 않고 **콘텐츠 스튜디오**(상품 한 줄 → 기획 방향 3안 → 쇼츠 제작 키트)까지 한 흐름 |

대회 규정: **3분 미만**, 문제 → 입력 → AI 처리 → 결과 → 가치를 **실제 화면**으로 보여 준다. 제출물은 영어이므로 자막·내레이션은 영어로 한다.

## 한 줄 이야기

> 아이스 흑당 라떼 마케터가 이번 주 쓸 밈을 고르고(근거 확인) → 피할 밈을 걸러 내고 → 상품 한 줄로 쇼츠 제작 키트까지 만든다. 같은 밈이 나라마다 어떻게 다른지도 본다.

심사 배점(기술 40·임팩트 25·혁신 25·UX 10)에서 기술 점수는 **AI가 한 일이 화면에 보일 때** 받는다. 그래서 장면마다 "AI가 무엇을 읽고, 규칙이 무엇을 정했는지"가 한 화면 안에 보이게 배치했다.

## 실제 프로토타입과 맞춰야 할 것 (중요)

이 화면은 **예시 데이터로 도는 기획 시안**이다. 대회 영상은 Cloud Run에 배포된 실제 서비스(`apps/trend-web`)로 찍어야 하므로, 시안의 각 장면이 실제 기능 중 무엇에 해당하는지 맞춰 둔다.

| 시안 장면 | 실제 서비스 | 상태 |
| --- | --- | --- |
| 이번 주 트렌드(세 카드·단어 구름·순위) | 지역 키워드 대시보드 `/trends`, 첫 화면 지도 `/` | 있음. '이번 주 할 일' 세 카드 형태는 없음 |
| 밈 자세히(판정·근거·관심도) | 사전 항목 `/dictionary/[termId]` | 있음 |
| 스튜디오 1→2단계(입력 → 밈 고르기) | 추천 `/recommend`(사진·문구 → 밈 최대 5개와 이유) | 있음. 시안의 '기획 방향 3안' 형태와 다름 |
| 스튜디오 3단계(제작 키트) | 만들기(SNS 카피·15–30초 대본·썸네일 계획) | 있음. 4컷 스토리보드 그림은 없음 |
| 나라별 비교 | 지도·국가 페이지 `/country/[code]` | 있음 |
| 무슨 뜻이야? | 메시지 해석 `/explain` | 있음 |
| 써도 될까? | 사전 항목의 리스크 | 화면 따로 없음 |
| 내 기획안·주간 리포트·브랜드 설정·타이밍 맵·쇼츠 링크 분석 | — | **없음** — 영상에 넣지 않는다 |

- **언어:** 시안은 한국어뿐이다. 실제 서비스는 한국어·영어 화면(`lib/i18n.ts`)이 있으므로 **영어 화면으로 녹화**하거나 영어 자막을 단다.
- **데이터:** 시안 수치(어울림 94점 등)는 예시다. 영상은 실제 수집 데이터로 찍고, 화면에 '예시 데이터' 표시가 남지 않게 한다.
- **AI 표시:** 실제 서비스에서 Gemini가 읽은 결과(제품 설명)를 화면에 보이게 하면 장면 3b가 산다. 시안의 'AI가 이렇게 이해했어요' 줄을 실제 `/recommend`에 옮기는 것을 권한다.

## 녹화 팁

- 1920×1080, 브라우저 확대 110~125%로 글자를 키운다. 커서는 천천히, 클릭 전 0.5초 멈춤.
- 로딩(밈 매칭)은 편집에서 잘라 1초 이내로 보이게 한다.
- 장면 전환은 메뉴 클릭 대신 Alt+숫자, 편집 때 컷으로 잇는다.
