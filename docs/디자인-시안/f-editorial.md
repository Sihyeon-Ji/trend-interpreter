# 디자인 시안 F – 에디토리얼 (2026-09-29, 검토 4차 반영)

관련 [디자인 개편](디자인-개편.md) · [프론트 방향](프론트엔드.md) · 브랜치 `lab/f-editorial` · 화면 `/lab/f-editorial?edition=KR`, `/lab/f-editorial/m/[termId]`

현재 앱(회색 표 중심의 관리 콘솔 같은 화면)은 그대로 두고, 동료 검토용으로 `/lab` 아래에 더한 시안이다. 방향은 **마케터를 위한 주간 밈
매거진** – 캐릿(Careet)의 정신을 빌리되 브랜딩은 빌리지 않는다. 고른 시장(판)의 '이번 호' 를 읽는 것이 첫 화면이고, 밈 항목은 한 편의 기사다.

## 누구를 위한 무엇인가

- 대상: 브랜드 마케터·에이전시·숏폼 크리에이터. 한국 사용자 우선, 영어 화면 함께. 만드는 콘텐츠의 시장은 한국·일본·대만·홍콩·동남아.
- 첫 번째 일: **매주 한 번**, 내 시장에서 지금 쓰이는 밈·식어 가는 밈·조심할 밈을 한눈에 보고, 하나를 골라 바로 만들러 간다.
- 두 번째 일: **매일 잠깐**, 지난번 이후 달라진 것(새로 실린 밈·뜻이 바뀐 밈·검색 급증)과 내가 담아 둔 밈의 단계 변화를 1분 안에 본다.
- 세 번째 일: **올리기 전**, 밈 하나의 뜻·유래·브랜드가 써도 되는지를 몇 초 안에 확인한다.

## 글꼴과 크기

- **Pretendard Variable 하나.** 이미 전역으로 실려 있고 굵기 45–920 을 쓸 수 있다. 세리프 디스플레이는 검토 뒤 뺐다(아래 '기본값에서 고친 것').
  가나·한자·태국 글자 이름은 시스템 폴백이 맡고 `lang` 을 붙인다(`lib/lang.ts`).
- 역할: 포스터 800 / 자간 −0.045em / 행간 0.95 · 제목 700 / −0.02em · 본문 400 · 라벨 500. 숫자는 `tnum`.
- 크기: 13 · 15 · 16 · 18 · 20 · 24 · 32 · 44 · 64 · 96 · 128. 표지 이름 `clamp(52px, 9.5vw, 128px)` – 긴 이름은 두 단계(88·64)로 내린다(`posterSize`, 한·중·일 글자는 넓게 셈).
  항목 제목 `clamp(40px, 7vw, 96px)`, 꼭지 제목 26–32, 포스터 카드 이름 24–28, 색인 줄 이름 18, 리드 18–22, 본문 16/1.75, 작은 글 13.
  이름은 낱말 사이에서만 줄을 바꾼다(`word-break: keep-all`). 본문 줄 길이 40em 이하.

## 원칙

1. **이름이 그림이다.** 밈 대부분에 영상·사진이 없다. 표지도 카드도 이름을 크게 세우고, 유튜브 영상이 실제로 있을 때만 썸네일을 잇는다.
2. **판정은 데이터, 문장은 쉬운 한국어.** 꼭지는 생애주기·목록 규칙으로만 나뉜다. 표지도 규칙이 고르고 어느 규칙인지 표지에 적는다. 뜨는 밈이 없으면 "이번 주에는 새로 뜨는 밈이 확인되지 않았습니다" 라고 적는다.
3. **구조 장치는 정보다.** 격자선은 칸을 가르고, 바이라인의 세로선은 사실을 가르고, 숫자는 건수다. 순위 숫자는 실제 순위(검색 상승)에만 붙인다. 눈썹 라벨·장식은 없다.
4. **대담함은 한 곳.** 코발트 표지 하나. 닫는 추천 안내도 조용한 선 하나로 둔다.
5. **커뮤니티 글은 신호로만.** 화면에 나오는 출처는 참고 위키·기사·영상뿐이고, 수집기가 news/web 으로 넣은 블로그·브런치·위버스·카페도 이름으로 거른다. 조심 이유는 인용 없이 쉬운 문장으로 옮기고, 백분율은 표본이 작을 수 있어 '전부·절반 넘게·일부' 로만 말한다.
6. **긴 목록은 훑게, 적은 것은 크게.** 포스터는 셋 이상일 때만, 하나둘이면 넓은 줄. 색인 줄은 8개까지 펼치고 나머지는 접는다.
7. 접근성 바닥: 390px 가로 넘침 0, 옆 여백 16px 이상, 초점 테두리 3px(표지 위에서는 흰색), `prefers-reduced-motion` 이면 표지 등장 애니메이션 없음, 원문 이름마다 `lang`, 차트는 키보드 십자선과 표로도 본다.

## 참고에서 가져온 것

- 캐릿: 주간 잡지의 리듬, 유행중 스티커, 요즘어 사전의 '이름이 큰' 항목. 노랑·스크립트 로고·사진 콜라주는 가져오지 않았다.
- TikTok Creative Center: 지역이 제목인 구조("한국판"), 순위 줄에 추세선 → 색인 줄의 추세선.
- Pinterest Trends: 고른 트렌드의 순위 목록 + 성장률 → '검색이 늘어난 밈' 의 순위 숫자와 %.
- Exploding Topics·Glimpse: 차트가 주인공인 표지, 성장 %.
- Know Your Meme: 항목의 유래·확산 서술, 출처 목록. 광고·다열 배치는 가져오지 않았다.
- Google Trends KR·썸트렌드: 실시간 검색 급증 줄과 그 이유(→ '갑자기 많이 찾은 검색어', 이유를 찾은 것만).
- 다른 시안에서 접붙인 것(검토 권고): o-editorial 의 스크랩 비교(담을 때 vs 지금)와 출처 목록 규칙(참고 문서 우선, 같은 기사 한 번, 주소에 경로가 있는 것만), 나이대별 20일 창 규칙, 빈 판 안내, 조심 점검표 열; o-report 의 UGC 이름 거르기.

## 기본값에서 일부러 고친 것 (계획 검토)

- 처음 계획의 **세리프 리드**를 뺐다. 크림 바탕+세리프+테라코타는 생성 화면의 흔한 얼굴이고, 가나·태국 이름이 섞이면 세리프가 폴백으로 깨진다. Pretendard 800 대 400 의 굵기 대비로 잡지 느낌을 낸다.
- **테두리·그림자 카드**를 **격자선**으로 바꿨다. 칸마다 선을 그리고 줄 끝 칸은 오른쪽 선을 뺀다.
- "COVER STORY" 같은 대문자 눈썹 대신 문장체 라벨 "이번 주 표지". 메타는 가운뎃점 문자열 대신 가는 세로선으로 가른 사실 목록.
- 4차에서 **띄어 쓴 줄표("한국판 – … 호", "제목 – 출처")를 모두 뺐다**: 호 날짜는 제목 아래 제 줄, 출처는 제 칸, 띠는 쌍점, 바닥글은 낱개 요소.
- 붙임표 한 칸에 뜻 하나: 카드는 단계(생애주기)만, 퍼진 정도는 표지·바이라인·사실 칸에서만.
- 먹은 `#17191C` 같은 중립 검정 대신 코발트와 한 식구인 남색 `#111A33`.
- 호 번호("제 39호")를 지어내지 않고 보드 시각의 날짜 범위로 쓴다.
- 닫는 안내는 처음 계획의 먹색 면을 버리고 선 하나 – 대담함은 표지에만.
- 뺀 장식: 호 머리의 소개 문장. 매주 오는 사람에게는 광고 문구다.

## 검토 기록

1. 1차: 곡선이 없을 때 표지 오른쪽 열이 비어 별이 화면 가운데 떴다 → 열을 하나로 접고, 곡선 대신 유래·출처를 오른쪽에. 격자 바탕색 방식이 회색 덩어리를 남겼다 → 칸마다 선. 휴대폰 제호 메뉴가 갈라졌다 → 줄바꿈 금지, 초안 목록은 바닥글로.
2. 2차: 꼭지 건수와 카드 수가 어긋났다 → 쪽 안의 수만 센다. 일본판에도 네이버(한국) 검색 상승 꼭지가 떴다 → 한국판·전체판만. 소개 문장 삭제.
3. 3차: 조심 이유에 커뮤니티 글 인용과 `(bsky.app)` 이 그대로 나왔다 → 인용을 뗀다. 상호작용 실측(별표 유지, 방문 띠, 찾기, 초점, 움직임 줄이기).
4. **4차(독립 검토 둘 반영)** – 상(高)·중 지적은 전부 고쳤고, 하 지적도 고쳤다.
   - 자료 정책: `web` 근거를 전부 내던 것 → 참고 위키 주소만. `news` 로 들어온 블로그·브런치·위버스·카페·SNS 는 이름과 주소로 거른다(`visibleKind`). 경로 없는 주소(`https://youtube.com/`)는 근거가 아니다. 나라별 차이의 '현지 밈' 은 이름꼴(24자·세 낱말 이하, 해시태그·계정·따옴표·문장 아님)만, 되풀이되는 목록은 처음 나온 나라에만. 스크린샷 전부 다시 찍음.
   - 표지 출처가 첫 화면으로 가던 것 → 참고 문서 우선, 없으면 가장 오래된 기사(`originRefs`).
   - '이번 주 달라진 것' 이 판을 안 가리고(일본 성인 용어가 한국판 첫 줄) 자리 표시("근거 부족")를 찍던 것 → `/updates` 에 카드를 붙여 카드의 지역으로 거르고(`changeRows`), 자리 표시는 내지 않고, 단계·조심 붙임표를 붙인다. 절을 표지 바로 아래로 올렸다.
   - 390 옆 여백 0·1440 머리 어긋남 → `.fe-issue`·`.fe-band__row` 는 `padding-block` 만.
   - 9.5k px 카드 목록 → 포스터는 뜨는 중·절정·검색 상승만, 나머지는 색인 줄 8개 + 접기, 조심은 점검표, 빈 꼭지는 한 줄, 앞 꼭지에 실린 밈은 다음 꼭지에 다시 싣지 않는다(조심 점검표만 예외 – '무엇을 피할까' 는 완전한 목록이어야 한다, 안내문에 적음). 검색 상승은 실제 순위라 번호를 붙였다. 5.4k px.
   - 조심 이유가 잘리거나("사전 뜻풀이에 적힌 주의점" 뒤가 빔) 기계 말투("위험 유형이 붙은 근거 5건")이던 것 → 사전 뜻풀이의 주의점은 글을 살리고, 아는 꼴은 쉬운 문장(두 언어)으로, 백분율은 '전부·절반 넘게·일부' 로.
   - 표지가 백엔드 순서 1위(조심 밈)이던 것 → 규칙으로 고르고 기준을 적는다. 이번 한국판은 '지금 쓰이는 밈 가운데 검색이 가장 많이 늘어난 밈'(과몰입).
   - 성장 계산이 달력을 벗어나고 표본 검사가 없던 것 → 나이대별 달력 28일 창 + 20일 이상 자료 + 셋 이상 나이대 + 오래된 곡선 제외. 카드 추세선은 0–100 고정 눈금.
   - 전체판 추천 링크 `regions=KR` → 목표 지역 전부, 세계판은 지역 없이.
   - 출처 건수와 목록이 어긋나고 같은 기사가 네 번 → 주소·제목으로 한 번만(포털 꼬리 " - Chronicle-Tribune" 도 뗌), 12건 + '나머지 n건 보기'.
   - 빈 판 탭이 2:1 회색 비링크 → 보조색 링크, 빈 호는 안내와 '전체판 보기'.
   - 하나뿐인 꼭지의 빈 격자 → 넓은 줄. 4열 격자의 외톨이 칸 → 3열로 꽉 차면 3열.
   - 곡선 십자선(마우스·화살표 키·Shift 7일)과 값 읽기, 5열 표.
   - 접붙임: 내 목록에 담을 때의 단계·조심을 적어 두고 달라진 점을 말한다(항목 머리에도).
   - 실측: 별표 2개 → 새로고침 뒤 유지, 담을 때 단계를 바꿔 두면 "담을 때는 ‘막 퍼지기 시작’, 지금은 ‘늘어나는 중’", 방문 시각을 어제로 돌리면 띠 "… 방문 이후 16건" 과 '새로' 16개, 찾기 두 글자에 1건, Tab 으로 표지 버튼까지, 곡선에서 ←·Shift+← 로 "2026.09.16: 10대 –, 20대 –, 30대 8, 40대 33, 50대 이상 25", `reducedMotion: reduce` 에서 애니메이션 없음, 내 목록 줄의 빼기 단추 오른쪽 끝 = 격자 끝(넘침 아님).
   - 검토와 다르게 둔 것: 표지 밈은 제 꼭지에도 남긴다(표지 기사는 목차에도 오른다 – 빼면 "뜨는 밈이 없습니다" 가 거짓이 되고 순위에 구멍이 난다). 조심 점검표는 앞에 실린 밈을 다시 적는다(위 참조).

## 아직 못 한 것

- 판은 한 지역씩이다(전체판 제외). 여러 시장을 같이 고르는 것은 없다.
- 검색 상승 %는 나이대별 상대값(각 나이대 최대 100)의 변화를 가운데 값으로 모은 지수다. 캡션에 계산법을 적었지만 절대 검색량은 아니다. 백엔드가 한 곳에서 같은 식으로 계산해 주면 시안마다 다른 숫자가 나오는 일이 없어진다.
- 목록의 2쪽 이후는 "다음 쪽" 링크로만 넘긴다(식는 중 68).
- 영상 썸네일 분기는 있으나 지금 데이터의 `short` 근거는 주소가 `https://youtube.com/` 뿐이라 화면으로 확인하지 못했다(백엔드 수집 문제).
- 새로 실린 일본 성인 용어(アヘ顔)는 일본판에 '판단 보류' 로 실린다 – 리스크 규칙이 아직 판정하지 않았고 화면은 판정을 지어내지 않는다. 懶人包 '사용 자제', 위버스 글이 `news` 로 들어온 것도 백엔드 몫.
- 조심 이유의 백분율 원문은 표본 크기를 주지 않아 숫자를 버리고 정도로만 말한다. 백엔드가 건수를 주면 "12건 가운데 5건" 으로 적을 수 있다.
- 공용 파일은 건드리지 않았다. 굳이 고친다면: `lib/data.ts` 에 곡선 여러 개를 한 번에 받는 로더가 있으면 한국판에서 항목마다 한 번씩 묻는 것(44회, 300초 캐시)을 줄일 수 있다.
