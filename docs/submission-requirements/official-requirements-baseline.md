# 공식 참가·제출 요건 기준선

확인일 **2026-09-23** · [공식 FAQ](https://aibuildercup.com/Faqs.html) · [공식 Themes & Requirements](https://aibuildercup.com/themes.html)

## 참가·프로젝트 필수 조건

- 팀원은 JAPAC 지역 기반의 만 21세 이상 working professional, entrepreneur 또는 startup 구성원이어야 합니다.
- 학생이 한 명이라도 포함되면 팀 전체가 실격될 수 있습니다.
- 팀은 2~4명이며 한 사람은 여러 팀에 참여할 수 없습니다.
- 한 팀은 하나의 문제·테마에 하나의 솔루션만 제출합니다.
- 프로젝트는 행사 기간에 새로 시작한 것이어야 하며 기존 프로젝트를 재사용할 수 없습니다.
- 작동하는 end-to-end 프로토타입이어야 합니다.
- Gemini·Gemma 또는 지정된 Google agent platform을 의미 있게 사용해야 합니다.
- Cloud Run·Google Cloud·Firebase 중 지정된 Google Cloud 경로로 배포해야 합니다.

현재 저장소는 2026년 9월 17일부터 기록돼 행사 시작 이후 생성 증거가 있습니다. 실제 제출 후보를 고르면
후보별 최초 commit·외부 자산·재사용 코드 범위를 별도로 확인해야 합니다.

## 제출물

| 제출물 | 보수적인 완료 기준 |
| --- | --- |
| 배포 링크 | 평가 기간 동안 공개 접근 가능하고 핵심 흐름이 실제 동작 |
| 데모 영상 | **3분 미만**으로 문제·입력·AI 처리·결과·가치를 실제 화면으로 시연 |
| 공개 GitHub 저장소 | 실행 가능한 소스·설치·아키텍처·AI/Cloud 사용 설명 포함 |
| 제안 deck | 지정 템플릿을 사용하고 PDF로 변환, 문제·영향·실현 가능성·확장성 설명 |
| 테마 지정 | 공식 여섯 테마 중 하나와의 연결을 명시 |
| 언어 | 코드·문서·발표 자료를 포함한 제출 자료는 영어 |

로컬 `submission-template.md`는 3~4분 영상을 적고 있으나 공식 FAQ는 **under 3 minutes**라고 명시합니다.
불이익 위험을 줄이기 위해 3분 미만을 기준으로 사용합니다.

## 공식 페이지 내부의 불일치

Themes 페이지 상단은 공식 여섯 테마를 제시하지만 제출 설명 일부는 Healthcare·Education·Accessibility 등
다른 category 목록을 사용합니다. 주제 선정과 deck에는 여섯 테마를 사용하고, 실제 제출 form의 category
필드가 다르면 화면을 캡처해 문의처에 확인합니다. 추측으로 두 분류를 섞지 않습니다.
